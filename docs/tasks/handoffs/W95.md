## The capability demonstration, which is the row's value

⛔ **A fixture asserted to be shared-origin without this is the vacuous shape the
project keeps catching.** The population in full, then the scalars:

```
shared-origin units: 2
    field-notes/unit-01 | origin: field-notes/topics.md | section: 1. Taking a reading
    field-notes/unit-02 | origin: field-notes/topics.md | section: 2. Writing it down
    |logical keys| = 2   |origin paths| = 1   |units| = 2      <- the collision
depth1 units: 3   |logical keys| = 3  |origin paths| = 3  |units| = 3
depth2 units: 5   |logical keys| = 5  |origin paths| = 5  |units| = 5
```

⭐ **A path-derived key collides (1 key for 2 units); the ruled key's positional
half does not (2 keys for 2 units).** Both halves are asserted, and the second
alone would have passed on a fixture that could not collide.

## Decisions

**1. A third valid corpus, rather than giving the property to `depth1` or
`depth2`.** ⛔ The decisive argument is the README's own, one field along: a
whole-file `origin` and a *region* `origin` are **two code paths and each needs
an input** — exactly what it says about SF-10's two overlay shapes. Converting
an existing corpus to `container_api: 2` would have left the **v1** shape with no
fixture at all, and it would have changed a corpus twelve epics already test
against. This diff changes no existing fixture's meaning; it adds one.

**2. `sibling` placement, and the source material committed.** Two consequences,
both deliberate. The golden *shows* the shape — both units' artifacts land in one
directory, named by ordinal and title, so provenance is visibly shared while
identity is visibly not. And committing the two source files makes this the
**only** corpus on which `validate` reports nothing `Unchecked`: measured, the
`short-read` and region checks run here and are `Unchecked` on both others.

**3. `REQUIRED_TYPES` declares three block types, not eleven.** The corpus exists
for one property. A second coverage corpus maintained for a reason that is not
its own is a fixture that drifts.

**4. The derivation lives in the test module, not in a new `fixture_checks`
seam.** Its only consumer today is this module. ⚠️ `SF-16` will want it; when it
does it moves to `tests/fixture_checks/origins.py` as a seam with a row in the
package's table — see *For dependents*.

**5. Nothing in the fixture names the corpus that provoked the question.** R1.
The shape is the subject; the measurement that motivated it stays in
`docs/tasks/E04-narration.md`, which is where a source-specific fact belongs.

## Surprises

**1. ⛔ My own plant contradicted me, and that is how the fixture got fixed.**
Predicted, in writing, before the command: stripping the fences from the shared
source file would make a fence-blind count read **5** headings where there are 4
and **3** in unit 1's region where there are 2, reddening `short-read`.
**Measured: 7 and 2, and `validate` stayed clean.** The injected pseudo-headings
were `#` — **depth 1**, which is *shallower* than the region's depth-2 opening
heading, so they **terminated** the region instead of inflating it. The fixture's
own prose asserted the false numbers. Corrected by making those comment lines
`###`; re-measured, a fence-blind count now reads **6** in the file and **4** in
the region against a recorded 2, and `validate` reports
`short-read: its source carries 4 heading line(s) and the archive records 2`.
⭐ Without row 2 of the three readings this fixture would have shipped carrying a
claim it did not support.

**2. `tests/fixture_checks` was already behind the framework on two versions.**
`CONTAINER_API = 1` against a shipped `CONTAINER_API == 2`, and `CORPUS_API = 1`
against a shipped `CORPUS_API == 2`. The first gated this row and is fixed by
importing `KNOWN_CONTAINER_API`; the second is a finding below.

**3. Losing the subject is silent without the inhabitation pin — measured.**
Re-pointing unit 2 at a different file made `GROUPS` empty: the five
group-parametrized tests **skipped**, `test_a_valid_corpus_passes[shared-origin]`
stayed **green**, and `test_the_path_derived_key_space_is_smaller_exactly_where_a_file_is_shared`
**passed on its else-branch**. One test reddened — the inhabitation pin. It is
the whole guard.
