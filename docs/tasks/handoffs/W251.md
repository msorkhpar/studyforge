## Decisions

- ⛔ **The detached line does NOT move `corroborate`'s exit.** `W153/3`'s ground: a carrier is
  declared on its branch, and a row claims a branch or a checkout token. A detached HEAD has
  neither, so it cannot be dispatched work under `W153`'s contract, and the gate (`dispatched
  and UNNAMED`) is itself a notice. The read copies are legitimate standing checkouts, so a
  fold would move the exit on every run on this host. Reversible: return the count.
- **Basename and seven-character head, never the path** (R7).

## Surprises

  names*. Nothing reported it: that was the hole.
