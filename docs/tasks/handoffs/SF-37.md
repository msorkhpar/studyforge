## Decisions

⭐ **The population is the PLAN's population, not *"what I found"*.** `studyforge
plan` and `validate.paths` both mint the four directories from
`container.units`, so this does too. A build that used the units it found
material for agrees with both instruments on the two shipped fixtures and
disagrees on the first corpus with a declared, unbuilt unit —
`with_a_unit_missing` makes that visible rather than leaving it to a consumer.

⭐ **The destination is ASKED, never composed.** Every copy lands at
`UnitLocations.media_dir(kind) / <basename>` — the two calls `Placement.media` is
itself made of — so the copy and the href agree by construction.

⛔ **`SF-32`'s verdict is NOT consulted, and no size policy is re-derived.**
`corpus.media` weighs what is on disk and answers a **git** question —
`ignore_lines`, `require_committable`. The order is build → measure → verdict:
consulting it inside the copy would weigh a footprint that is half written, and
`require_committable` refusing mid-build would stop a build over a repository
decision. ⚠️ The copy is what makes the footprint non-zero for the first time, so
`SF-32`'s instrument has an input now where it had none.

⛔ **A missing file is a RECORD, not a policy.** `Written.missing` names it and
the build continues — the same shape `refused` has had since the first pass.
Whether a build stops on one or drains them into a report is `W195`'s and stays
untaken.

⭐ **`copy` rather than `place(…, source.read_bytes(), …)`.** A lesson video is
megabytes; a build that read every one into memory to hand it straight back out
would be sized by the corpus.

Acceptance's own wording — written before anything emitted a poster. One media

⛔ **The archive's own media location was declared NOWHERE in `src/`** — see
`SF-37/1`. Both shipped fixtures use `<archive>/<address>/units/unit-NN/`, the
spec's contract table names a file inside it, and `FND-04`'s handoff states the
resolution rule in prose; no code said it, so every reader was composing it.
