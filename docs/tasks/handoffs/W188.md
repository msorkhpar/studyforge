## ⛔ THE STRUCTURAL FINDING — the skip's stated reason was NOT the cause

⚠️ **Measured at `35bf14e`, host, `wt/dev3`:** the live observation table carried
rows and `0` declaring a started state — ⛔ **not because a wave had closed, but
because EVERY row's State cell read `MERGED`, which the closed vocabulary does
not carry.** ⭐ `STATES` carries `done`; the register writes `MERGED`.

⛔ **`0 declaring a started state` had two causes and the reading named neither.**
⚠️ **And the same cause stands down a SECOND instrument:** `corroborate`'s
row→branch assertion is gated on `row.started`, so it printed *"not a started
state; no carrier is owed"* on every row of the live board. ⭐ **Both instruments
were correct** — the rows really are closed — ⛔ **but neither could distinguish
*correctly closed* from *no cell was understood*, which is `NONE FOUND` one
column over, and is what `W111` was bought to end.**

⚠️ **THE RESIDUAL RISK, and it is the register's call, not mine:** a row that is
genuinely IN FLIGHT but whose State cell is written outside the vocabulary reads
`started = False`, so the contradiction rule stands down, `corroborate` stands
down, and the board looks clean. ⭐ **The count is now printed on every floor and
corroborate run, so the condition is visible.** ⛔ **It is NOT flagged, and adding
a flag today would go RED for the board being in a state its owner chose** — the
register table asserts `undeclared == []` live and the scheduled table asserts a
state on every row; **the observation table is the one of the three with no such
arm.** ⭐ **That arm is the register's to ask for.**
