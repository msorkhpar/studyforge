## Decisions

- **The whole heading marker is stripped, not only the hashes' position.** Taking `HEADING`'s `text` group also drops closing hashes, which a bullet twin carries after the link and never reads.
- **A numbered heading that links a file of regions stays a container.** An ordinal on a label is not a reason to read it as an entry, so W250's reading is pinned by a test here.

## Surprises

- ⚠️ The SF-02 draft test survived P1. This fixture's draft does not depend on any entry's ordinal. The record tests are the discriminating ones, and the SF-02 test is the judge, not the detector.
