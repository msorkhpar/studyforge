## Decisions

**1. The seam is `classification` | `completeness`, and it was measured rather
than chosen.** Three things say so, and none of them is taste:

- ⭐ **Two tasks a week apart drew it independently.** `SF-35` landed entirely
  on the classification side, `SF-36` entirely on the completeness side; the
  only place they collided was a shared insertion anchor for rule constants
  (`BOARD.md`, `CTO-31/6`). `SF-36/2` is a recorded negative saying the author
  declined to split at 399/400 *because the seam was the one the other task was
  working across* — that seam is this one, now free.
- ⭐ **The module shed a whole concern and came back larger.** `validate/headings.py`
  (134 lines) left one commit before I started and the residue still grew
  377 → 425. A module that does that is not one module needing a tidy.
- ⭐ **Nothing crosses.** No name defined in either half is read by the other;
  what they share is `Walk`, `Finding`, `Unchecked` — which every check in
  `validate` shares. `test_the_seam_holds_and_neither_half_imports_the_other`
  asserts that rather than trusting this paragraph.

⭐ **The 94-line module docstring split along the same line without a sentence
being rewritten to fit**, which is the strongest evidence available that the
seam is real: §"What counts as material is the corpus's declaration" is
classification's whole rationale, §"A completeness check counts something the
parser did not produce", §"A unit may be a REGION" and §"Where the source is"
are completeness's. That is the check R11 §3c actually asks — *can someone
understand what this unit does without reading its internals* — answered by the
document the previous authors already wrote.

**2. The CTO's proposed shape (`CTO round 32`) is followed with one deviation,
stated.** That table put *"the shared scan, `_read`, and the module docstring"*
in `__init__.py`. ⛔ **Measured at `426672c`, neither is shared:** `source_files`
(with `Scan`, `_walk`, `_declared_output`, `SKIP_DIRS`, `IGNORE_TIMEOUT`) has
exactly one caller, `check_unclassified`; `_read` has exactly one caller,
`_compare`. Putting them in `__init__` would make the package contract a home
for two private things that belong to one half each — and `module-structure.md`
is explicit that `__init__.py` **is the contract**. ⭐ They sit with their only
caller; `__init__.py` holds the contract, `CHECKS` and `__all__`, and nothing
else.

**3. The one import-surface change: `count_headings` is no longer reachable
through `validate.source`.** It never was on purpose — `source.py` did
`from studyforge.validate.headings import count_headings, region` and the name

`validate.headings`. ⛔ **Ruling 101's producer half says a name a second
package needs is exported from the owner's surface, never reached for past
it**, so re-exporting it here would have written the deviation down as a
contract. The only importer was the test mirror; it now imports from
`studyforge.validate.headings`. **No `src/` module is affected.**

**4. The seven `count_headings` rows stayed in this package's mirror rather
