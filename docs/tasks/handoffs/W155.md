## Surprises

⚠️ **THE ENVIRONMENT CHANGED UNDER A MEASUREMENT AND TWO READINGS TAKEN
MINUTES APART DISAGREED, AND THE CAUSE WAS ANOTHER OFFICE'S GIT CONFIG.**
⛔ Linked worktrees SHARE one `.git/config`. Mid-wave, that config carried a

⭐ **PROVED NOT MINE BEFORE IT WAS REPORTED.** The 327 file-and-line pairs from
the poisoned run over MY tree and from a run over the MAIN checkout's tree —
which holds none of my changes — are **byte-identical**, and **0** of the 327
names a file in my diff.

⚠️ **A second surprise, and it is the one that makes the first reportable:** in
the pinned image `HOME=/tmp` and there is no passwd git identity, so
`identifiers()` returns `['hostname', 'short hostname']` and this arm is
silent — *unless* a worktree writes a repo-LOCAL identity, which the mount
carries straight in. ⛔ So the container is not the insulation the module's
docstring says it is.
