## Decisions

- ⭐ **Sibling module, not a package.** Ruling 352's grep for `navigation.py` pointers in frozen
  records exits `1`, so no pointer stood in the way, but the seam is two questions, not a
  package's worth.
- **The sweep flags a `#` that INTRODUCES a fragment** — one not after whitespace, `#` or `&` —
  in any non-docstring literal. It exempts comparisons and the first argument of a string
  search. This catches `"#".join`, `chr(35)` and `"\x23"`. `"%c" % 35` and `map(chr, [35])`
  survive, and a test reads each of them.
- **`FRAGMENT` is imported by no producer**, because none needs it: both producers ask
  `anchor`. See `W107/3`.
