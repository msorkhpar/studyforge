## Decisions

1. ⭐ **Placed at `src/studyforge/exitcodes.py`, a flat module at the top of the package**, beside
   `version.py`, `describe.py` and `sourcepath.py` — which is the shape this repository already
   uses for "the module everybody imports and which imports nobody". ⛔ **Not under `cli/`**, and
   the reason is structural rather than aesthetic: `validate` has to import it too, and no stage
   may import the dispatcher's package — the direction is one-way, so a stage stays runnable as
   `python3 -m studyforge.<stage>` with the dispatcher absent. ⭐ Asked the row's way — *where would
   it go if `validate` did not exist?* — the answer is the same, because the constant is about the
   invocation and not about any material.
2. ⛔ **Exactly one constant moved.** `OK` and `INVALID` are verdicts about an archive; moving them
   would widen into `validate.report`, which is not on this surface, and would put two stage-owned
   verdicts in a module that belongs to no stage.
3. ⭐ **`__all__` added to `validate/cli.py`** so that the re-export is declared rather than
   incidental. Three other non-package modules in `src/` already carry one, so this is the standing
   shape and not a novelty.
4. ⚠️ **The clause "one definition, imported by both" is asserted over the TREE, not over the two
   modules** — every module under `src/` is read for an assignment to `UNUSABLE` and exactly one may
   have it. See the surprise below for why an identity assertion could not do this job.

## Surprises

- ⛔ **`is` cannot detect a second definition of a small integer, and the plant is what found that
  out.** The mirror first asserted `validate.cli.UNUSABLE is exitcodes.UNUSABLE`; P3 — a second
  `UNUSABLE = 2` left behind in `validate/cli.py` — **passed it**, because CPython caches small
  ints and both names then point at the same `2`. ⭐ The assertion was replaced by a sweep of the
  source tree, which P3 reds by name. ⚠️ Any handoff or review that treats `is` as proof of "one
  definition" for a small int, a short string or `None` is reading nothing.
- ⚠️ **A dependency from the shared module onto a *stage* is not merely caught, it is impossible.**
  P4b does not fail a test — it fails collection, with a circular `ImportError`, because
  `validate/__init__.py` imports `validate.cli`, which imports the shared module. ⭐ That is a
  stronger guarantee than the test, and P4a (a non-stage framework module) is the plant that
  exercises the test itself.
- ⚠️ **Removing the exemption caught nothing that had been hiding behind it.** The question the row
  asks is answered `no`: with `HELD` gone the sweep reports `[]`, the `validate` parametrisation
  that `W293` had to skip passes, and no other module was found arriving with the command. ⛔ The
  exemption was exactly one constant wide.
