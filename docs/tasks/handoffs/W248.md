  and `check_archive_members` are on the package surface.

  headings moved to the derived counts.

## Decisions

- **Beneath a map that did not parse, nothing is judged.** `run` already reports that no
  document there was read, and a finding per file would be many findings for one defect.
- **A `.json` at the wrong depth beneath a variant is not a stray.** The walk reads it, and
  `identity` refuses it. A non-`.json` file at the same place is never read, so it is a stray.
- **Unit files are asked of the address**, the way `generate.media` asks. A unit's files beside
  a map held at another directory are strays, beside that map's `address-directory`.
- **No git consult under the archive.** An ignored stray is still refused: the archive is the
  adapter's, not the repository's to declare.
- `cli/plan/` has no diff. Plan reads maps at the root it prints, and nothing in the contract
  needed it.

## Surprises
