## Decisions

- **The identity checks pass `builds_fresh=True`.** A differing `pyproject.toml` re-runs the step that pip-installs setuptools from the index, so these checks need network on any cache.
- **A default HOST run now does two things with docker.** Both are ruled as reversible, and neither builds or pulls:
  - The gate starts one `--network none` container per session.
  - The live gate test commits a throwaway image and removes it.
