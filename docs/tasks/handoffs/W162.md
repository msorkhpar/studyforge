## Decisions

- **The identity checks pass `builds_fresh=True`.** A differing `pyproject.toml` re-runs the step that pip-installs setuptools from the index, so these checks need network on any cache.
- **A flagged COLD cache skips; it does not build.** The committed clause says a test run must not need network. `docker/dev/check` warms the cache outside a test run. Ruled reversible: `W162/8`.
