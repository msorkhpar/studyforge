## Decisions

- **Keep, not refuse.** Refusing would refuse three Java lesson files that read today, including the step lists the row describes. Java has no manifest at `c9cf522`, so which of its files are material is not yet declared.
- **An optional key after the fields, not a fourth required field.** A key on every list would move every document's `content_sha256`, ISO's committed archive included. Placed after `items`, it leaves the three fields in their order, so a checker can compare a prefix.
- **`start` is recorded only when it is not `1`**, and `0` is kept. A leading zero reads as its integer. `list_start` treats a non-integer or a boolean as absent.
- **The speech-id grammar is unchanged.** A clip's words change only for a list that carries `start`.

## Surprises

## For dependents

- **`W263`:** a `list` block's keys are its `fields` then, optionally, `BLOCK_OPTIONAL["list"]`, in that order.
- **Any consumer of an ordered list:** read its first number through `archive.blocks.list_start`, never `block["start"]`.
- **`M8` (Java corpus):** three lesson files and the root readme gain `start`. Their words are unchanged.
