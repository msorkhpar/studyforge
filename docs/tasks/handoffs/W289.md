## Decisions

- ⭐ **`W290` landed as TWO public spellings, not one, and the row's clause is still met.** The clause is *one call takes the unit's source, so no call site spells the label*. A single function cannot serve both callers: [`containers.py`](../../../src/studyforge/generate/containers.py) and `media.py`'s `_declared` walk **declared** units, and `_sources` never builds a `UnitSource` for a unit with no material on disk — so there is no source to pass. ⛔ The property the row is about is *nothing is spelled at a call site*, and that holds at all six: `declared_location` takes the container and the unit whole. The alternative — synthesising a throwaway `UnitSource` with an invented `directory` and `declared_practices` — would have put two fabricated fields into a placement question to avoid a second name.
- **`counts_of` refuses; `validate`'s `check_counts` still filters first, unchanged.** They are not in conflict and neither is redundant: `validate` drains and reports every finding (R6), so it must not raise, and [`check_block_shapes`](../../../src/studyforge/validate/blocks.py) already names the block. The builder is the opposite case — it is refusing to write a document, and there is no report to drain into.
- **`where` is an optional argument rather than a required one.** Required would have made this a three-call-site change for no reading: `validate` and the fixture checker pass object blocks and never see the refusal.
- **`_types_of` reads each block once** instead of eleven times. Not an optimisation for its own sake — it means a refusal cannot depend on which count key was being tallied when the bad block was reached.
- ⛔ **No row file, and no row in [`BOARD.md`](../BOARD.md), was edited.** State lives once, in the register, and it is the PO's.

Had I taken the row's four on trust, `media.py` would have kept spelling the label out and the new sweep would have gone RED on the first run.

- ⭐ **`archive/blocks.py` had no `describe` dependency** and every other refusal in the archive already used one. The contract line was accurate before and is accurate now; it needed the edit.

## For dependents

- ⛔ **`unit_location` no longer takes an address, ordinal, title, origin and label.** A caller with a `UnitSource` calls `unit_location(corpus, source)`; a caller walking `container.units` calls `declared_location(corpus, container, unit)`. Both are on [`generate`](../../../src/studyforge/generate/__init__.py)'s `__all__`; nothing should import [`generate.declarations`](../../../src/studyforge/generate/declarations.py) directly.
- ⭐ **To vary a label in a test, vary it on the SOURCE** — `dataclasses.replace(source, label=…)` — because that is where the one derivation reads it from. [`test_stage.py`](../../../tests/studyforge/cli/narrate/test_stage.py) and [`test_narration.py`](../../../tests/studyforge/generate/test_narration.py) both do this now, and both still assert the label actually moves the audio directory before relying on it.
- ⛔ **A third placement derivation must be added to `DERIVATIONS` in [`test_declarations.py`](../../../tests/studyforge/generate/test_declarations.py)**, which is a closed set on purpose: a new one that is not listed is simply not swept, and the control test only proves the *listed* names are still called.
- ⭐ **`counts_of` is now a function that can raise.** A caller that must drain rather than stop — any `validate` check — filters to object blocks first, as [`check_counts`](../../../src/studyforge/validate/structure.py) already does. A caller that is writing a document should let it raise.
