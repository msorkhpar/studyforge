## Decisions

- **Generated text may not cite an aliased id either.** The row's first clause could be read
  as "no id that is not an alias". But `SK-09/2`, the id the finding names, is an alias, and a
  stranger reading a corpus has no decisions file. So the test requires the population
  command to print nothing at all.
- **The page bundle is in scope.** The row points the reading at `skills/`, and its Surface
  names "any other emitter the reading finds". The corpus reading found `page.css` and
  `page.js`, the most-cited framework text the ISO corpus commits.
- **The test uses its own settled draft.** Onboarding's shared fixture carries a person's
  reason that cites `W266`, and `corpus.json` copies a person's reason verbatim. That is the
  person's text, not the framework's, so the test settles its draft with a plain reason. The
  shared fixture is untouched (`W461` is in onboarding).
