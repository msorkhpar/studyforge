## Decisions

- ⭐ **A painter, not a marker or an exemption.** The trail is authored on every generated
  unit page, so without a painter it shipped as a numbered `<ol>`. `DEFERRED` would have
  needed a live owner, and no task paints the trail.
- **`recognisable` is `REGIONS`**, and the existing owner tests carry the painting from there.
  No `nav` marker was added to `REGION_MARKERS`, because the authorable sweep supersedes one.
- **Not a static-only census.** The browser checks RAN in the pinned image under
  `STUDYFORGE_VISUAL=required`, and the reach census now opens the trail.
