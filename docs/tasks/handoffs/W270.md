## Decisions

- **The check runs at `write`, not in `onboard()`.** `write` is where the corpus root, and so the sibling, is known. `onboard()` and `lines()` stay pure, and step 3 refuses before anything is written.
- **`check_held` is a separate function, and `check_commit` stays the shape half** used by the renderers. An optional checkout argument would have been a check that stands down silently whenever it is omitted.
- **The checkout is the sibling named `studyforge`**, the way every stub already finds it. It is resolved first, because `Path(".").parent` is `.`.
- **The tests use a synthetic framework whose commit is deterministic** (`corpora.framework_beside`): an empty tree, placeholder identities, a fixed date, and no user config. `corpora.COMMIT` is that sha, and `material()` makes the sibling. The helper asserts the sha matches, so drift is loud.
