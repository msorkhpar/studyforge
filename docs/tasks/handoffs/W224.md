## Decisions

- The copy's source is the directory the page's disk probe used, so a clip is copied exactly when its page plays it.
- At the corpus root, `Written.missing` still names absent clips, so `missing` means the same thing for every `--out`.
- A recorded filename that carries a directory stops the build (`BuildError`) and is a refusal in `plan`. The value is never echoed (R7).
