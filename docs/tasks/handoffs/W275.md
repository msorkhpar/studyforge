## Decisions

- **The refusal is a floor finding, not an exception.** `W247` raises `IndexRefused` because its index is built in one call. Here a raise would crash the floor and break `delivery.py`'s reading of `rows`.
- **The census line is unchanged, and it prints no refusal count.** A refusal already moves the floor's exit code, and the brief asked for the same output before and after.
- **The shape lives in `creators.py`, not in `board/`.** `board/delivery.py` also types it, but that file is `W274`'s surface this wave. See `W275/2`.
- **The addition was kept compact rather than splitting the module:** the refusal is built as a `Finding` where it is found, with no carrier class. The module now stands at the R11 ceiling, not over it. See `W275/1`.
