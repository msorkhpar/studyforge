## Decisions

- ⭐ **Presence is the manifest's declaration read against the disk, never git or the plan.** `classification.source_files` depends on both, and the package seam forbids importing it.
- ⚠️ **The reading is anchored where the origins point, not the whole root.** A whole-root reading turned four FND-04 invalid fixtures RED, each on a second rule (`W255/2`). ⛔ The gap is declared and asserted (`…_DECLARED_an_origin_whose_top_directory_is_ABSENT_…`), per [Ruling 292](../../conventions/review-rubric.md#ruling-292-an-acceptance-with-n-arms-met-by-a-population-of-m-n-shapes-is-satisfied-by-declaring-the-extra-arms-with-an-assertion-each). Reversible.
- An excluded file counts as present: withheld prose is still the source on disk.
