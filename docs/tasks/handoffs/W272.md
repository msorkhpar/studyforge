## Decisions

- ⭐ **The survey mirrors `validate`; it does not skip and name the difference.** A nested `.studyforge` is a source's own directory (`W259`), so a survey that skips it drafts without reading material `validate` will classify. Mirroring removes the disagreement instead of describing it. Reversible: restore the two names to `NOT_MATERIAL` and drop `stores`.
- ⭐ **The stores are `validate`'s answer, not a walk of this module's own.** `source_files` honours the repository's ignore declaration, which a second rule would not. Plant P5 shows it.
- ⚠️ **The report gains one line on every run**, the store count. SK-07 prints `survey('.').lines()`, so the change is additive there. The draft manifest's shape is unchanged, so `promote` and the generated `corpus.json` are untouched.
