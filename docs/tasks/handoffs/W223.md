## Decisions

- ⛔ **An old record READS, and every clip in it is judged STALE once.** `narration_api` stays `2`. No entry's keys change; the top-level `conditions` gain `engine_model`, read as absent. Old fingerprints were taken without a model, so none equals one taken with it. The next run asks for every clip with the reason *the conditions changed*, and drops no entry. ⭐ The cost is bounded by the service: its address includes the model, so an unchanged model answers `cached`.
- **`/healthz` without `engine_model` is unreadable**, as it already was without `chunk_chars`. A non-string value records `null`, as a non-int `chunk_chars` does. The key is read, never composed (R20: nothing here reads the sibling).
- **A `Narrator` protocol rather than a type-checking-only import.** The tree has protocols and no `TYPE_CHECKING` block.
- **`field_of`'s field parameter is named `what`**, so the emission census reads it as a label, as it reads `where`.
