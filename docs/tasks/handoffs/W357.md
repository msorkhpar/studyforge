## Decisions

### Clause 1 — one record, whose grader half is optional as a whole

⭐ **Decided: the `exercise` record may name a file with no test.** It then carries
`main_path` and `run_command` and nothing else. The grader half (`test_path`,
`test_command`, `provenance`, and `trust`, which is defaulted) is written in full or
left out in full. ⛔ **A separate declaration was considered and rejected.**

The argument, read at `b9aef83`:

1. ⭐ **Every consumer that resolves a file already reads one place.** The unit
   document's `workspace` is `exercise.to_document` of this record
   (`unit/builder/parts.py`, `workspace_of`). `SF-44`'s definition in
   [`E05`](../E05-serving-execution.md#sf-44--the-terminal-command) resolves a file
   "to its unit's exercise in the generated unit document (§7: `main_path`,
   `test_path`, `run_command`, `test_command`)". `SF-22`'s Run reads the same
   `workspace`. With one record, unit 3's file and run command reach that place with
   no new key in the archive document and no new key in the unit document.
   ⛔ A separate declaration needs a new top-level archive key
   (`archive/document.py`, which is at 393 lines, so it would also need a split), a
   new section key in the unit document (a unit-document contract change), and every
   file-resolving consumer would then search two keys for one question.
2. ⭐ **The state is still read off the structure, with no flag.** Before: graded is
   "the `exercise` key is present". After: graded is "the record names a grader"
   (its `test_path`). ⛔ The grader half is all or nothing, so a half-written grader
   is still refused. That was the old refusal's purpose ("an ungraded exercise
   wearing the graded key"), and it survives.
3. ⭐ **R5 stays on the one record that has a grader.** `provenance` and `trust` are
   facts about a grader (§7: *"`provenance` is a fact about where the grader came
   from"*). A record with no grader has neither, and writing either one on its own
   is refused.

⚠️ **The cost, stated.** *"The key's presence is the graded state"* stops being
true. Anything that tested key presence, or `workspace is not None`, to mean graded
would now be wrong. ⭐ **Measured at `b9aef83`:** in `src/`, the only thing that
decides graded is `exercise.states.state_of`, and this row changes it. `SF-22` is
in flight and reads `workspace`, so this is reported as a finding for it.

### The version — `raw_api` stays `1`

⭐ **Not a `raw_api` change.** The rule for this document is in
`archive/document.py`: *"Bumped when a reader of the old shape would be wrong
rather than merely incomplete."* Every document that was valid before is still
valid and means the same thing, and an older build refuses the new shape (its
record is missing `test_path`) rather than misreading it. §7 already set the
precedent that `exercise` rides `raw_api` 1. Spec §6 applies the same test to
`list.start` and nested lists (*"Not a `raw_api` change, because every document
without … reads exactly as it did"*).

⛔ **Why this differs from `W350`.** `W350` raised `corpus_api` because an author
declares that version, and `KEY_VERSIONS` refuses a key under a version older than
the one that introduced it. `raw_api` is not declared by an author. `build` writes
it from one constant, so raising it would re-render every archive document
written so far (R10) in order to announce a relaxation.
