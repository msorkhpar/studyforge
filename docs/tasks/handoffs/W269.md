## Decisions

- ⭐ **Covered files hold their directory.** Otherwise a directory glob re-proposes a covered file with the uncovered one beside it.

- ⛔ **An unreadable manifest reads as no declaration**, as an unreadable onboarding record already did, and the reasons question prints the covered count.
