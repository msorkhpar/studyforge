## Decisions

- ⭐ **An instrument, not only a clause.** The row's third clause and the brief's plants have to be able to turn RED. A clause in prose can be checked only by reading it. A command's output can be asserted. The command also makes the population size a printed count and an exit code, and it closes Ruling 142's fold for an office that never reads that ruling. Reversible: delete the module, its mirror, and the rubric's command block.
- ⛔ **Not in `CHECKS` or `NOTICES`.** It runs the suite. A floor check gives the same reading for the same files and never runs a test.
- ⭐ **The runner's report is JUnit `xunit1`, not `-rs` text.** It carries each test's file, line and reason, so nothing is folded and nothing needs parsing out of prose.
- ⚠️ **The `grep` figure counts the census's tests whose own body names `helper(`.** It does not count call sites. A call-site count is not a bound on tests, because one test can call the helper twice.
- ⛔ **It removes variables and never sets one.** So it cannot open a gate. Every test uses a synthetic module in a temporary directory.
