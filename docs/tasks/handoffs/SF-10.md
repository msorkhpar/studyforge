## Decisions

**`built_from`, not `sources`.** Ruling 51 forbade `sources`, `source` and
`origin`; `source` stays the corpus id one level up. ⛔ And no entry records a
path — the lesson `workspace.json` paid for. An entry names the variant, kind,
ordinal, ingest date and digest, which identify the document inside the unit
whose address is on the document above it.

**`practices` is two counts and no verdict.** `declared` is `None` when nothing
declared one, which is not zero and must not render as it. ⚠️ *Complete*,
*short* and *unknown* stay `studyforge validate`'s single job.

**The gate runs in `material` and again in `served`, and that is not a re-ask.**
Ruling 50: two trust boundaries, one read path each. `material` delegates to
`archive.document.load`; `served` gates because **`validate` is optional**, so a
serve-time reader assuming it ran trusts a promise nobody made.

**A `PersonalDataLeak` is never translated into this package's error type.** A
caller walking a corpus catches `ContentError` per unit and reports the rest; if
an R7 refusal were in that family it would be logged as one more unit that did
not build. ⚠️ See finding 60 — `unit/content.py` does the opposite.

**An authored section's blocks are the author's.** The archive document behind
it supplies `video` and `workspace` and nothing else — the exact promise
`DERIVED_FIELDS` makes from the other side. See finding 61.

## Surprises

⚠️ **The 2.1× expansion figure over-predicted, and the survey said it was one
data point.** Predicted ~500–600 lines for the port; measured **712** across
seven modules — but the largest, `document.py`, came in at **182** against a
predicted ~290. ⭐ Ruling 55 exactly: *a number in a ruling is a measurement
from an instrument, never a property of the tree.* The seams were the reason to
make it a package; the ratio never was.

⚠️ **Two repository-level checks fired on shapes they had never met**, and both
were right to look: W7's gate coverage met the first module that reads documents
**only by delegation**, and the emission probe met a new `parse`. ⭐ The second
worked exactly as designed — a new reader became an obligation. The first did
not; see finding 59.

## Findings

### 59 `[structural]` — W7's tell cannot tell decoding from delegating, and Ruling 50 makes the difference load-bearing

`tests/test_gate_coverage.py` flagged `unit/builder/material.py`: it calls
`archive.document.load`, which decodes **and gates**, and never calls
`assert_clean` itself. ⛔ Both available fixes were wrong — adding the call is
the re-ask Ruling 50 forbids, and renaming the import to dodge the grep is
worse. ⭐ **Ruling 52 applies: this is a case W7 never argued over**, so it is
named rather than stretched.

⚠️ **Amended to the check's own stated intent** — its docstring already says
*"`json.loads` is the tell"* — so `DECODES` is now `("loads", "json.load")` and
`_calls` records a module-qualified name alongside the bare one. All six
existing readers are still found; two new tests pin both halves, including that
a delegating module is **not** a reader. ⛔ **The narrowing is the CTO's to
ratify**, and if it is refused the alternative is a way to declare delegation,
not a call.

### 60 `[structural]` — one R7 refusal, two behaviours, three modules

`unit/content.py` catches `PersonalDataLeak` and re-raises it as `ContentError`;
`builder/material.py` and `unit/served.py` let it through as itself. ⚠️ **Both
are defensible and they cannot both be right.** Translating means a caller
looping over units logs a leak as *"that unit did not build"* and finishes; not
translating means an R7 refusal stops the run. ⛔ Not changed here — `content.py`
is SF-09's and this is a ruling, not a patch.

### 61 `[local]` — the first authored build used the archive's blocks

An authored section's blocks are the **author's**; my first implementation
passed the archive document's. ⭐ Caught by the overlay's own refusal — *"1
section(s) and no blocks in any of them"* — because the fixture had empty
authored blocks, so the defect surfaced as a fixture error rather than as wrong
output. ⚠️ Worth recording: the two shapes differ in **content** as well as in
order, and the survey named only the order. **Fixed**, and `parts.section` now
takes `blocks` explicitly so neither shape can inherit the other's.

### 62 `[local]` — the emission probe's reader count was a literal

`assert len(readers) == 6` sat below a derived membership check. ⚠️ A count
nobody updates stops meaning anything, and it is the same shape as Ruling 48's.
Now `len(covered) - 1`, derived from the set above it. **Fixed.**
