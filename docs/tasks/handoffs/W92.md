## Decisions

- **Which field the side is read from, and why it is derivable rather than
  guessed: the row's `**Owns**` cell.** It is the only per-row field any epic
  document carries that says where a row's work lands, and the grammar for
  reading it is already **decided**, not invented here — Ruling 292, in
  `tools/quality/plan_parse.py`, which
  [`board/delivery.py`](../../../tools/quality/board/delivery.py) already uses
  to split its own reading into a framework and a sibling column.
  - ⛔ **Not the epic id.** [`README.md`](../README.md)'s two-agent table
    splits epics between the two agents, but `E09` is mixed — `OPS-05` owns
    framework code and its neighbours own corpus paths — and `E10` carries
    `QA-04`. A per-epic field would state the wrong thing for those rows.
  - ⛔ **Not a path prefix.** *"It starts with `src/`"* is knowledge about
    this repository's layout, and the next repository's plan does not use it.
    The pin document is the declaration; the reading resolves against it.
- **Three values, not two.** ⛔ A row that owns *"the findings log"* names no
  path at all, and calling it `this framework` would be an invention printed
  as a reading. ⭐ It is `undeclared`, and the hole is countable — which is
  `W92/1`, the finding this row settles by naming rather than by guessing.
- **A `why` for a row that is not on this side is REFUSED, not discouraged.**
  ⛔ The row's defect is that the field forced a false statement; a field that
  merely *permits* a true one leaves the false one writable.
- **The column is conditional.** ⭐ A column that would say the same thing in
  every row says nothing, and the row's *must not become* names a fifth column
  nobody reads. This also makes the *both ways* assertion exact: a document
  set where the distinction does not apply renders what it always did.
- **`capability.py` was SPLIT, never trimmed (R11, Ruling 261).** It was at
  the 400-line ceiling. ⭐ **The seam: reading a document is one job, being the
  index is another.** `capability` answers *what does the plan declare* and
  knows nothing about workspaces, components or sides; `index` answers *when
  does X land, and is it ours*. The test mirror moved with it.
- **`Backlog.checked` now returns a plan carrying the checked statement.** A
  statement checked and then thrown away would render neither new population.

## Surprises

- ⚠️ **The reading was already decided and already implemented — in `tools/`,
  by Ruling 292, for a different consumer.** The index could not reuse it:
  `src/` may not import `tools/`, which is the same rule that made `SK-02`
  re-declare `SOURCE_LINE_CEILING` and `capability.py` re-declare
  `ROW_ID`'s first half. So the grammar is written a second time, and the two
  are asserted to agree by measurement rather than by construction (`W92/3`).
- ⚠️ **The `Owns` cell is not on the declaration line.** `**Milestone**`
  opens the block and `**Owns**` is usually the next line, so the walk had to
  read the whole block up to the next blank line. That is what
  `tools/quality/plan_parse.py` already does, and the previous walk here read
  one line only.
- ⛔ **The pin document is read by pattern and never decoded, and that was
  forced rather than chosen.** `json.loads` makes a module a *reader of
  somebody's document* under `W7`'s coverage check, and every such module in
  `src/` must call the personal-data gate (R7) — which this package's own
  contract forbids it to import, because a planner reasons about work and not
  about a corpus's contents. ⭐ The first draft used `json`, and
  `tests/gate_coverage/test_coverage.py::test_every_document_reader_calls_the_gate`
  is what found it. Two declared strings per entry are taken and nothing else.
- ⚠️ **17 rows own no path at all**, which is more than the row's 13 and is
  a different population — the row's 13 was a reading taken in another
  repository and is not re-measured here (Ruling 115).

## For dependents

- ⛔ **`capability_index` and `Index.of` take one more argument.** Omitting it
  is a `TypeError`, not a quiet *everything is this framework's*. The third
  argument is the **text** of the pin document; `Components.none()` is how a
  caller declares there is no component but its own.
- ⛔ **`Backlog.checked(index)` returns a NEW plan** — use the return value.
  It carries the checked terminal statement, which is where the rows that are
  not this framework's arrive.
- ⭐ **`Capability` now carries `owns`, and `Epic` carries `preamble`.** Both
  are verbatim text; neither carries a side. The side is `Index.sides`.
- ⚠️ **Regenerate the index when an epic's `Owns` cell changes**, not only
  when a milestone moves.
  `test_the_shipped_index_is_exactly_what_the_generator_produces_today` is
  RED until somebody does.
- ⭐ **The rendered document names no component**, so a consumer that wanted
