**Status:** done.

## What landed

- ⭐ **`studyforge.corpus.manifest.RAISES`** = `(ManifestError, PersonalDataLeak)`.
  ⚠️ `AddressError` is **not** a member: `parse` translates it in `_slug_of`, and
  only `Manifest.parse_key` lets it out. A test asserts that property, so the day
  the translation moves, a test fails before a command crashes.
- ⭐ **`studyforge.generate.RAISES`** = `(BuildError, PersonalDataLeak)`, and
  `studyforge build` (`cli/site/cli.py`) catches it.
- ⛔ **Every try around a `corpus.container` or `corpus.manifest` reader now names
  the reader's `RAISES`**: `cli/plan/derive.py` (×2), `generate/declarations.py`
  (×2), `validate/corpus.py` (×2) and `skills/onboarding/manifest.py`. The false
  `SF-28/1` comment in `declarations.py` is gone, replaced by a citation of the
  contract.
- ⛔ **Sites that treat the leak differently keep their own arms**:
  `except PersonalDataLeak` comes first (a re-raise, or validate's
  `personal-data` rule), then `except RAISES`.
- ⭐ The convention is written once, in `docs/conventions/module-structure.md`
  under *Docstrings are the contract*.

## Decisions

⛔ **The row's crash was not the live one.** At `5d37f73`, `build` on a
wrong-depth map already refused (exit 2, naming the file and the depth), through
the `AddressError` arm whose comment was false. ⭐ **The live crash was the
leak**: `cli/site` caught `BuildError` alone, so a home path in a container map
or in `corpus.json` left `build` as a traceback (exit 1) that named absolute
source paths. It is the same shape (a caller holding a subset of what its
package lets out), so it was taken. See `W212/1`.

## Surprises

⚠️ **The sweep is name-only.** A `RAISES[:1]` in a handler passes it. Plants
P1a, P4, P6 and P9 did exactly that and survived the sweep; each was caught by
that caller's behavioural test instead.

## The sweep's population (at `5d37f73`)

- **Enumeration 1, text:** `git grep -nE "except .*(ContainerError|ManifestError|PlacementError|DiscoveryError|MediaError|RAISES|AddressError|PersonalDataLeak|ArchiveError)" -- 'src/*.py'`.
  **32** lines: **30** `except` clauses and **2** docstring or comment mentions. Every line was read.
- **Enumeration 2, AST:** the `tests/studyforge/corpus/test_init.py` sweep finds
  every `try` whose body calls `parse`, `load` or `from_document` imported from
  either reader. It found **7** sites, the list above, and asserts that set as
  its floor. Reader calls with no `try` around them: `skills/onboarding/onboard.py`
  (×2), which let everything propagate.
- **Examined and not converted:** `placement` and `discovery` callers. Their
  package's only pass-through is `PersonalDataLeak`, and Ruling 58 already
  settles its handling, so a tuple would add nothing. `validate/corpus.py`'s
  `ArchiveError` site belongs to `archive`, which is not `corpus.*` (`W212/4`).
