## What landed

- `tools.quality.report.unreachable_population(stats)`: the tests a run skipped, counted and grouped by the reason each skip gave. It is derived from pytest's own tally and prints `unreachable population: 0 skipped test(s) — …` when nothing was skipped. It returns lines and never an exit code.
- The root `conftest.py` prints it from `pytest_terminal_summary` on every run, on the host and through `docker/dev/check` alike.
- `test_scheduled.py` reads the board through `repository_root() / BOARD`. A new test calls both live readings from a directory that is not the root.

## Decisions

- **The disclosure lives in a pytest hook, not in `docker/dev/check`.** Only the run holds its skips. The wrapper is POSIX shell that `exec`s any command, so it could only parse the output by giving up the exit pass-through. It is also an image build input ([`W225.md`](W225.md)). The hook prints the same line in both environments, which is the point of Ruling 326 ([`review-rubric.md`](../../conventions/review-rubric.md)). `docker/dev/check` is untouched, so the image identity does not move.
- **Every skip is disclosed, not only sibling skips.** Filtering for the sibling reason would be a typed list. The host's in-image and ruff skips are the other half of the same non-superset.
- **A module-level skip counts as one**, the same unit pytest's closing line uses.
