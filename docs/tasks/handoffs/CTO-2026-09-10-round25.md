# ⛔ The three judgements I was asked for

## ⭐ Ruling 85 — the fourth lint state is **RATIFIED**, and generalised

⛔ **The author found a state Ruling 78 did not name — installed, and it would
not answer** (unexpected exit, unparseable report, timeout, process will not
start) — implemented it, and filed it as a **gap in the ruling** rather than as
an implementation detail. ⭐ **That is the right call and I am ratifying it.**

⚠️ **The alternatives are both worse.** Letting the exception escape would make a
*notice* crash the floor — turning it into a check and making the floor's verdict
depend on ruff's behaviour, which is exactly what Ruling 77 forbids. Swallowing
it would print a false `clean`, which is the silence Ruling 78 exists to close.

⛔ **And it must stay distinct from `absent`**, because the two have different
remedies: *absent* says install it; *would not answer* says it **is** installed
and something else is wrong.

⭐ **Generalised into the rubric at §1f, because the reflex is what recurs, not
the module:** a reason field carries an **exit code**, a **timeout with its
bound**, or a **failure class** — ⛔ **never a captured stream, a filename or an
argv element.** A captured stream is the richest source of absolute paths we
have. **This binds every check and every notice.**

⛔ **The shape:** a test that sizes its own input off the constant it is meant to

a sweep rather than a reviewer**.

⚠️ **But "sweep the repo for that shape" is an open-set instruction**, and §8a's

  | probe | ruff `E501` | floor `[line-length]` |

  | 117-char line ending `# type: ignore[assignment]` | ⛔ **1** | 1 — **they agree** |
  | 116-char unsplittable `'aaaa…'` literal | 1 | 1 — **they agree** |
  | 114-char line containing `https://example.invalid/…` | ⭐ **0** | ⛔ **1** |
  | 120-char comment containing `https://example.invalid/…` | ⭐ **0** | ⛔ **1** |

  ⭐ **A/B, identical lines differing only in the URL scheme:**
  `# see https://example.invalid/bbb…` (120) → **ruff 0**;
  `# see zzzzzzzzzexample.invalid/bbb…` (121) → **ruff 1**.
