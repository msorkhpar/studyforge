## Decisions

- **The declaration lives in the bundle's header, not in a Python list.** R1 stays true: the framework knows the asset it ships, and no corpus's languages. A corpus manifest never carries a language list.
- **The page says which language fell back, not the build report.** The caption is where a reader sees a plain block, and the build report is outside this row's surface.
- **The fallback is `plain`, a grammar Prism declares empty,** rather than an unknown `language-gherkin`. The fallback is then itself declared and checked.
- **No grammar was added.** A local disk search found no Prism source for the four missing grammars, so adding one needs a download, which is `INT06-9/1`. Grammar text lifted from another application's minified bundle would not be the unmodified Prism 1.30.0 that `prism.LICENSE` and the header describe.
