## Decisions

- **A narrate run that fails is a state and never a stop.** Validate and build stop the run with their own exit code.
- **The states print once the site is listening**, from `serve`'s `started=` hook, because the toolchain state is read from the namespaces the serving process offers.
- **`--out` must already exist.** The skill creates nothing (`W202` Q1 is open).
- **All three `VALID` fixtures are served**, not only the two `SF-39` served.

## Surprises

- ⚠️ **A process test lost lines**: `for line in process.stdout` reads ahead, and `communicate()` then reads the raw pipe, so buffered lines vanish (`SK-03/5`).
- ⚠️ **A relative `PYTHONPYCACHEPREFIX` turned the adapter and onboarding walkthroughs RED**: their subprocesses write `.pyc` files into the temp corpora, and `validate` reads those files as unclassified (`SK-03/7`).
- ⚠️ **One plant survives an arm by design**: a page write spelled through `getattr` passes the static check. The runtime arm catches it.
