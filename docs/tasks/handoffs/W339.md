## Decisions

- ⭐ **Only one direction is asserted.** `exercises: false` means no graded work,
  so the cell must say *none*. ⛔ **The converse is refused on purpose**:
  `exercises: true` with no grader is C5's ungraded state (SPARQL's shape), and
  a check asserting it would refuse a true row. A test holds that non-assertion.
- ⭐ **The pinned commit, not the checkout.** The pin is what this workspace says
  it builds with, and a sibling on another branch is not the workspace.
- ⭐ **The resolver is imported, not re-derived**: `workspace_root` and
  `WORKSPACE_ENV` come from `tests/studyforge/corpus/placement/test_corpora.py`,
  the one module that already carries the override (`W138`'s rule against a
  third copy).
- ⚠️ **Where no manifest can be read, the real sweep SKIPS and says so** (Ruling
  204). That is the pinned image, where only the checkout is mounted. ⭐ The
  refusal is held both ways on a synthetic table under the real heading and
  columns, so the image still proves the instrument can go red (Ruling 191).
- ⛔ **The *Units* column is not read.** The row asks about graders. A units
  check would need the archive, and at the pin the archive disagrees with the
  ruling (`W339/1`).
