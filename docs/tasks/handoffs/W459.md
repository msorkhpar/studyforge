## Decisions

- ⭐ **The new entries alias the rows**, so a reader who meets `W453` in the spec's amendment
  text or `W450` in `tests/visual/` finds the entry. REL-09/6 asked for this.
- ⭐ **Spec-stated rulings still get their own entry.** The quiz key (§7 §7) and planning by
  aspects (§7 §4) are stated in the spec, and the file's convention is a pointer entry. The
  existing `Spec §7` pointer already exists and lists other aliases, so a second pointer for
  the same section would duplicate a heading's job. The new entries give the decision
  briefly, name the modules and name the spec section. They do not copy the spec's text.
- ⭐ **A coverage test for string literals, unlike REL-01's docstrings.** REL-01 kept coverage
  out of the test because docstring citations churn on every branch. A user-facing message
  that cites an unaliased id is the defect this row forbids, so a branch that adds one should
  go red.
- **Serves:** `W446` → `R5` (the lock protects the test that judges the reader); `W455` → `R13`
  (styling is read from the stylesheets, never re-typed); `W454` → `R7`; `W451`/`W452` → `R5`;
  `W453`/`W456` → `R6`; `W450` → `R8`.
