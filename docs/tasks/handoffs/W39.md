   is QUOTATION, and the rubric's vocabulary has four words** — a state the tool
   declines to print is a state the reviewer supplies from memory. ⚠️ **Before

2. ⛔ **The line is prefixed and greppable**, and the rubric names the grep

   before this change too; ⭐ **a bridge count from yesterday's graph is a claim
   about yesterday's tree.** Now recorded in the docstring rather than left as
   behaviour a reader must infer.

   verification of it was the half that carried the pass condition, and the pass
