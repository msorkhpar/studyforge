## Decisions

- ⭐ **Spelling: a flag, `--prune`, in a required mutually exclusive group with
  `--voice`** — not a new verb. It keeps `reconcile` (`OPS-07`) unpre-empted, and the
  parser makes *"a narration run cannot prune"* structural. The prune branch builds no
  client.
- ⛔ **A partial walk is a declared unit with no material** — `generate.declarations`
  skips it silently, and it is the only partial walk the tree can produce (`W218/4`).
- ⛔ **HELD, not deleted**: an entry whose filename is not its own clip name or holds a
  separator, an entry of a unit no longer declared (`W218/1`), and a non-file at the
  clip path. Held entries stay in the record and still count in the disclosure.
- Files first, then the record; only entries whose file is now absent are forgotten.
- Exit codes: `0` pruned; `1` refused or anything held; `2` unreadable corpus or record.
  The disclosure never moves `narrate`'s exit code.

## For dependents

- **A person:** `studyforge narrate <root> --voice <voice>` prints `dead record  N …`;
  `studyforge narrate <root> --prune` deletes those clips. `refuse walk` names the units
  whose material is missing.
- **Whoever adds a unit-scoped `narrate` or `reconcile` (`SF-28`, `OPS-04`, `OPS-07`):**
  a scope must land in `Walk.unwalked`, or `--prune` will read out-of-scope entries as dead.
- **`SF-42/1`'s fix:** the prune locates clips through the same `synth.audio_dir` the
  writer uses, so the two move together.
