## What landed

### The floor is the tree, not a figure

`Census` gained `walked`: module name → public callables probed in it, filled for **every** module
the walk imports, including those that define none. *Walked and found nothing* and *never walked at
all* are different failures, and a mapping that recorded only the first would deliver them as one.

`tests/test_emission.py` derives its population from disk instead of holding a number:

- `defined_on_disk(root, package)` parses every `*.py` under `src/studyforge` and records the public
  functions and classes each file **defines**. ⭐ It is a *different instrument* from the walk it
  measures — the sweep imports and introspects, this one reads source — so a package that drops out
  of the walk moves one and not the other. A typed bound moves with neither, which is exactly how
  three of them came to sit several times under what they guarded.
- `owing_a_probe(defined)` is the subset the sweep owes a probe. ⭐ **One exclusion, and it is
  `public_callables`' own**: a module whose public definitions are all exception classes owes
  nothing, because an exception formats what it is handed and that is every other probe's subject.
  It is asked of the imported object, so it tracks that rule rather than restating it as a naming
  convention free to disagree with it.
- `unwalked(...)` and `unprobed(...)` are the two comparisons, written once and used by both the
  live assertion and its plant — so a plant cannot pass against a re-implementation.

The three `LEAST_*` constants and the dated census comment beside them are gone. What is left at
whole-tree grain is inhabitance (Ruling 191): callables, parameter probes and path probes are each
asserted greater than zero, so an empty sweep can never pass.

### What replaces a floor on the parameter and path totals

Per-arm arithmetic, asserted where it is knowable exactly rather than as a whole-tree lower bound
nobody can derive without taking the census a second time:

- two data parameters are two single probes plus the all-at-once pass, and a label parameter is not
  probed at all;
- one path probe per path parameter, and the `str` beside them belongs to the other arm.

⛔ An arm that stopped making the combination fails these by one. A whole-tree lower bound could
lose a third of the census and still read green — which is the row's reading, restated as code.

### `W217/5`: the document census runs inside the containment

`document_census` wraps each reader in `contained(found.contained, reader.name, POISON_ROOT)` —
once per reader rather than once per probe, because the containment is what a call may touch and
that does not change between two fields of one document. `DocumentCensus` gained `contained` and
prints it, and `tests/test_document_emission.py` gained the escape arm plus the plant.

## Decisions

1. ⛔ **Refused: a bigger literal.** The row names it as the thing this must not become, and it
   buys one drift cycle for the same finding.
2. ⛔ **Refused: a second census.** The population inside a module is whatever `public_callables`
   yields; re-deriving it from AST would have to mirror every exclusion the probe makes — exception
   classes, re-exports, unfillable classes — and would then be free to drift from the thing it
   measures. ⭐ **What IS independently derivable is the module list**, and that is what the guard
   is built on. The finer grain is bought by asking, per module, *did the walk find anything here*,
   which needs no second selection rule.
3. ⭐ **Module granularity is argued, not assumed.** The gap between the AST-derived definitions and
   what the sweep probes is ONE category and it is the documented one: the `errors` modules, whose
   public definitions are exception classes. No allow-list, no exemptions, no names typed here.
4. ⭐ **Exactness both ways on the module list.** A sweep reaching something the tree does not ship
   is a walk that has lost its subject as much as the other direction, so the assertion is set
   equality and not only "nothing missing".
5. ⛔ **No inhabitance floor on the document containment.** Readers parse; a nonzero count of
   refused writes is not something the tree can be expected to produce, and asserting one would be
   a floor nobody can satisfy. ⭐ What keeps that arm non-vacuous is its plant.
6. ⭐ **The plants live in the file, driven through the same comparison the live assertion makes**,
   and the module they silence is taken from the derived population — so not even the plant's
   subject is a name typed by hand.

## Surprises

⛔ **The old floors would have survived an entire package leaving the sweep.** Planted in a
throwaway copy — `modules()` taught to skip one package of the framework — the new arms go **RED**
and name it, while the comparisons the three removed bounds made still held. That is the row's
claim measured rather than argued: the guard read as a guard and was not one.

⚠️ **The census is not the only reader of its own report.** `Census.report()` is printed into every
failure this file causes, so the module reach had to go in there too; a guard whose failure message
does not carry the thing that failed sends the next reader back to re-measure by hand.

## For dependents

⭐ **What a branch that ADDS a module now sees.** Nothing, as long as the sweep can reach it. The
obligation is derived, so a new module is covered the moment it lands — but a module that cannot be
imported, or one a walk stops yielding, is now named by this file rather than absorbed by a bound
with room to spare. ⚠️ **A module whose public definitions are all exception classes owes nothing**;
any other module that defines a public function or class owes at least one probe.

⛔ **What a branch that moves `tests/emission/probe.py` must keep.** `Census.walked` is filled in
`census()` and nowhere else, and it is filled for every module walked — including the ones with no
public callable. A refactor that fills it only where something was found reduces this guard to the
totals it replaced.

⭐ **For `W217`'s owner.** The containment is used, not changed. `document_census` is now inside it
(`W217/5`), and `DocumentCensus.contained` reports what it saw with the same lines
`Census.report()` uses, so the two censuses read alike in a failure.
