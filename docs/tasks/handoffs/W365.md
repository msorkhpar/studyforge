## What landed

1. **Both documents describe the file-only record and cite §7 for it.** Each
   links [*A file with no test*](../../specs/2026-09-08-studyforge-v1-design.md#a-file-with-no-test-w357)
   and says the rule is there, not here. The guide's states table now reads
   *ungraded* as "no `exercise` key, or an `exercise` naming a file and no
   grader", and *graded* as "an `exercise` naming a grader". Its new subsection
   shows the two-key record in a JSON block, says it has Run and no Submit, and
   names the two refusals in between: half a grader, and a `provenance` or
   `trust` with no grader. `E06` carries the same amendment under its SF-23
   table, and warns that the older Definition and Acceptance say *the key*
   where they mean the graded state.
2. **The fixture checker names the refusal under the rule it broke.**
   `_rule_for` returns `exercise-trust` only when the record carries every one
   of `GRADER_KEYS` except `DEFAULTED_KEYS` **and** `unit.trust` refuses its
   claim. Any other refusal is `exercise`. The keys are imported from
   `studyforge.exercise`, not spelled again.

## Decisions

- ⭐ **"Whole grader" is the test, not "carries `provenance`".** It matches
  `exercise.from_document`, which asks R5 only after `_require_present` has
  accepted a whole grader. So a record carrying `provenance: generated` and
  `trust: authoritative` with no `test_path` is named `exercise`, because the
  framework refuses it first for the missing grader keys and its message says
  so.
- ⭐ **The graded example stays the first JSON block with an `exercise`.**
  `test_authoring_reference.py` reads the first record shown as the full key
  set, so the file-only example comes after it. The new test states that
  order, so a reorder fails in this row's test file and not only in the other
  one.
- ⭐ **The new test is a separate file at `tests/` root, next to the other
  `test_fixture_*.py`.** `tests/fixture_checks/` holds helpers, not tests, and
  `tests/test_authoring_reference.py` is near the R11 bound and is not this
  row's surface.

## Surprises

- ⚠️ **`tests/fixture_checks/exercise.py` had no test of its own.** Its only
  reading was indirect, through the `user-authoritative` invalid fixture, and
