## Decisions

1. ⭐ **The fence filters and the skill does not change.** The alternative was to make `reonboard`
   drop a passed glob the manifest already declares. That would resolve two reasons by
   precedence, and `W283` refuses that on purpose. The fence reads `corpus.json`, which is
   reading and not hand-editing, so `hand_edited` still reads `[]`.
2. ⭐ **The refusal the brief named lives in `onboard.py`, not in `reonboard.py` or
   `recorded.py`.** It is `_carried`'s message. `reonboard` reaches it through `onboard`'s
   `existing=`. Only its string changed, plus 2 docstring lines. The file is at 390 lines.
3. ⭐ **The split.** The new tests took `tests/test_authoring_exercises.py` to 597 lines, which
   leaves no room under the ceiling. ⛔ **The seam:** that module reads the authoring
   *procedure* (the pass, its drafts and gates, and what it writes). The new one reads the
   corpus's *readiness* for the pass, which is *Before you author*. Both module docstrings name
   the seam.
4. ⭐ **Step 5 does not type the prime flag's spelling.** `EXECUTION.md` prints it from the
   contract's `runner.prime.declared_by` (`W440`), so the guide points at that document.
