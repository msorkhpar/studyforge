## What landed

- **A heading that links a file is not a unit by the link alone.** It is read as a **group label that names where its units are** when three things hold: it stands in the shape of the grouping's labels, it opens no entry, and the file it links is cut into regions. Its units are then those regions. Anywhere else it is still an entry. The argument is in `grouping`'s module docstring:
  - [§6](../../specs/2026-09-08-studyforge-v1-design.md#6-the-ingestion-contract) gives a container an `origin` just as it gives a unit one, so a link says where something is, not what role it plays. Role stays positional.
  - [Ruling 92](CTO-2026-09-10-round26.md#ruling-92-f21-origin-may-name-a-region-and-the-region-is-a-heading) makes a unit a region of one file.
- **`regions.cut(root, target)`** (new) returns a `Regions` with `sections` (exact heading texts) or `why` not.
  - Region depth is the shallowest depth that occurs twice. A single title above it is allowed.
  - A shallower heading after a region, or a section that is not unique, refuses the cut and is named in `why`.
  - It reads headings with `validate.headings`, the scan `check_completeness` uses to bound a region.
- **`Record`** now carries:
  - `Entry.section` on each sub-file unit;
  - `containers`, the files cut into regions;
  - `uncut`, the files at a label's position that are not cut.
- **`record.observe`** now reports:
  - the count `containers whose units are regions of one file`;
  - one question per container;
  - one question per uncut file, naming why it was not cut.
- `grouping.choose()` returns the labels with their lines. `grouping()` keeps its return shape and gains an optional `holds` argument.

## Decisions

- **A linked file with regions is still an entry if its heading opens entries.** That was the behaviour before this row, and the row does not reach it.
- **The heading scan is borrowed from `validate`, not rewritten**, so every proposed section is one `region()` resolves exactly once.
- **Every container is asked about.** A unit with two subsections has the same shape as a file of regions, so the proposal is never silent.
