## Decisions

- ⭐ **An instrument, not prose.** The brief's plants need something that can turn RED, and prose that says "compare the sha" is the same assumption the row exists to remove. Reversible: delete the module, its test and the rubric fence.
- ⭐ **The sha, and a merge commit.** The merge commit is made in the trial worktree, so no other checkout is at it. A `--no-ff` merge that makes no commit leaves `HEAD` at the base, a sha a release checkout also holds, so a non-merge `HEAD` is refused.
- ⛔ **The expected sha is taken on the host and passed in.** Inside the container every tree is `/workspace`, and a path outside it is a home directory (R7).

## Surprises

- The first fixture's reviewer tree was a plain commit. The sha-comparison plant would then have SURVIVED, refused on parent count. Caught by reading before the plant ran: the reviewer's `HEAD` is now a merge commit, as a release checkout's is.
- The trial merge's sha RESOLVES in the wrong tree (a shared object store), so resolving it proves nothing. The command compares `HEAD` instead.

## For dependents
