⭐ **A routing becomes a ROW when no live row holds its mechanism, and a FINDING in an existing
row's file when one does.** ⛔ **The reviewer's ground against a second RULING — *"exactly the
second copy that can disagree"* — applies unchanged to a second ROW**, and this round applied
it three times.

the removing round names the document and the STRING.** ⛔ **One candidate was refused on
exactly that test** — *one row per id, and the id space has exactly one minter* (Ruling 68) is
carried by no convention, so it stays until one carries it, and landing it is not this office's
surface. ⚠️ **`W173` owns the sweep; this round did three and stopped.**
