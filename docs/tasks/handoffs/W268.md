## Decisions

- **Ask every declared directory, mint only the filled ones.** Minting on demand in `copy` alone would have lost R3's by-name refusal for a directory nothing fills.
- **A re-build leaves old empty directories where they are** (R3). Git never tracked them, so a clone never had them. A local checkout keeps them until its owner removes them.
- **`plan` is untouched**, as briefed. [`validate/paths.py`](../../../src/studyforge/validate/paths.py) claims the four paths for collision checks and never needs them on disk.

## Surprises

- ⚠️ The offline-load test cannot be turned RED by bringing empty directories back. It asserts that no page needs a directory the build did not make, which holds with extra directories too. Its RED case would be a page addressing a file that was never copied, and SF-37's existing tests already own that case.
- ⚠️ `depth2` has a page reference to a media file the build names `missing`. It dangles with or without its directory, and it is excluded from the offline-load test by name (`W268/2`).
