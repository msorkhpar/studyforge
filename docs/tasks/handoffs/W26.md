## Decisions

### 1. ⛔ The map is the ruling, so it is asserted directly

`test_an_import_binds_the_name_it_actually_binds` pins `import_origins` on six
import forms at once. ⚠️ `import a.b.c` binds `a`; `import a.b as x` binds `x`
to `a.b`. Getting that pair backwards loses a whole dotted chain rather than one
segment of it, and it would have shown up only as a reader quietly disappearing
— which is the failure mode Ruling 57 exists to close.

### 2. ⭐ A shadowed import is **asked**, not assumed away — the noisy direction

Shape `J` imports `json`'s `load` and then binds the same name to something
else. What `load(path)` means there depends on which binding wins at run time,
and this file chooses to call it a reader.

⛔ **The asymmetry Ruling 57 is built on decides it.** W7 asks whether a module
that *might* decode has gated. The cost of asking is one argued false positive —
which is exactly what produced this ruling, productively. The cost of not asking
is silence. ⚠️ **Nothing in `src/` is written this way**, so the choice costs
nothing today; it is asserted so the next person cannot read the tie either way.
Both token spellings get `J` wrong in opposite directions, which is recorded in
the test.

### 3. `_calls` keeps only bare names now, and says so

Its dotted half existed for one consumer — `DECODES = ("loads", "json.load")` —
and that consumer is gone. `GATE` is one name, W13 guarantees there is one
`assert_clean` to reach for, and both spellings of the reach record the same
bare name. ⛔ The docstring was rewritten rather than left describing a
constant that no longer exists.

### 4. Left where it is, not extracted to `tests/support.py`

W13's rule is *extract at the second copy*, and this is the first. ⛔ Nothing
else in the tree resolves import origins, so extracting now would be a shared
helper with one caller.

## Surprises

### ⛔ Two mutants survived the first sweep, and both were real holes

The bar for this task was *every negative control is itself run negatively*. **22
mutants of the tell were built and run; 20 died on the first pass.** The two
survivors were not noise:

```
SURVIVED  _dotted claims an origin for an unimported base
SURVIVED  _calls blind to attribute calls (the gate half)
```

- **The first** replaced `_dotted`'s final `return None` with `return "json"`,
  so a call on the result of another call — `source.open().load()` — resolved to
  `json.load`. Nothing noticed, because **no probe had a base that was not a
  plain name**. Shape `L` was added and it dies.
- **The second** deleted the `ast.Attribute` branch from `_calls`, so the gate
  became invisible when reached for as `scrub.assert_clean`. ⚠️ **This hole
  predates this task and is not Ruling 57's**: every gated module in `src/` uses
  the bare name, so the tree never exercised that half, and neither did the
  suite — a gated reader spelling it the other way would have been filed as an
  R7 offender. `test_the_gate_is_seen_however_the_module_reaches_for_it` closes
  it. **After both fixes: 22 mutants, 22 killed, no survivors.**

## Findings

### W26/1 `[structural]` W7's coverage is bounded by the root it walks, and the bound is asserted nowhere

`document_readers` is called on `src/studyforge` only. Running the same tell
over the rest of the tree finds **three ungated document readers outside it**:
`tools/knowledge/index.py`, `tools/workspace/__init__.py` and
`tests/fixture_checks/corpus.py`.

⚠️ **Not a regression and not Ruling 57's** — the shipped token tell finds the
identical three. ⛔ **Not "walk more roots", either:** Ruling 31 forbids `tools/`
importing the framework, so `assert_clean` is unreachable from there and
`tools/quality/personal_data` is that side's gate. Extending the root therefore
means **naming a gate per root**, and `tests/fixture_checks/corpus.py` is W13's
known weaker copy wearing a third hat. A ruling, not a patch.

### W26/2 `[local]` The gate half of this file had no test of its own

No module in `src/` reaches for `scrub.assert_clean`, so the tree never
exercised attribute handling in `_calls` — and deleting it left the whole suite
green. A gated reader spelling the reach that way would have been filed as an R7
offender. ⭐ Closed in this diff; recorded because of *how* it was found — a
control going green, not a reading.

## For dependents

- **`DECODES` no longer exists.** The constant is `DECODERS`, it holds
  **origins** (`"json.load"`, `"json.loads"`), and adding a spelling to it is
  now meaningless — a new decoder is a new *origin*, e.g. a `tomllib.load`.
  `docs/tasks/handoffs/SF-10.md` §finding-59 and `CTO-2026-09-10-round18.md` §2
  both name the old constant; they are records of the argument and correct as
  history, so neither was edited.
- **`decodes(source)` is the reusable half** — a string in, a bool out, no file
  needed. Prefer it to re-walking the AST if a second check ever needs the same
  question. ⛔ Do not copy it; extract it to `tests/support.py` at the second
  caller, per W13.
- **`docs/tasks/BOARD.md` was not edited.** The W26 row is the PO's to close, and
  no developer branch this wave has written to the board.
- **A module that delegates still has no obligation**, and `unit/builder/material.py`
  is still the only one. If a second appears, nothing needs doing: it is
  correct by construction now rather than by the tell happening to spell things
  its way.
