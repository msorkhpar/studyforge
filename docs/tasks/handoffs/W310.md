## What landed

### ⭐ ONE VOCABULARY, AS DATA, THAT BOTH SIDES READ

`tools/reserved_addresses.py` holds `RESERVED_TLDS` and `RESERVED_DOMAINS` — RFC 6761's
reserved TLDs and RFC 2606's documentation domains — and two renderings of them:

- `is_reserved(domain)` — the membership question, for a caller that has already parsed an
  address. `tools.authorship` reads this and its own copy of the list is gone.
- `alternation(names)` — the same vocabulary as a regex fragment, for a caller that must
  find a name inside free text. The floor's `ALLOWED_ADDRESS` is BUILT from this.

⛔ **The module imports NOTHING** — not one standard-library module — and that is the
contract rather than an accident: it sits on the merge path through `tools.authorship`, so
a dependency added here is a dependency added to the merge path.

### ⛔ THE PROPERTY THE ROW MUST NOT SPEND, ASSERTED

`test_W310_the_MERGE_PATH_imports_NEITHER_the_framework_NOR_the_floor` walks the
repository-local import closure of `tools.mergegate` transitively and fails on any
`studyforge` or `tools.quality` name in it. ⭐ **It asserts the closure is INHABITED first**
(Ruling 191), so an empty walk cannot pass for free, and a second test points the same
walker at the floor's shapes arm — the OTHER reader of this vocabulary — where it must find
what the merge path must not (Ruling 123's row 3).

### ⛔ THE DRIFT IS PLANTED, NOT ASSERTED

`test_PLANTING_the_vocabulary_moves_the_MERGE_PATH_and_the_FLOOR_together` adds a fabricated
name to the vocabulary and reads BOTH sides: row 1 the live tree, row 2 both readings moving
on one edit, row 3 a name the plant did not add, unmoved. ⭐ **A side that went back to a
private copy would stop moving and turn the mirror red** — which is the guard, because a
divergence nobody can produce is not a guarded one.

## Decisions

⛔ **1. A MODULE, and not a table in a document — and the argument is that the precedent
does not bind here.** [`personal-data-shapes.md`](../../conventions/personal-data-shapes.md)
carries this repository's other shared vocabulary as a table two tests read, and that form
was **forced**: Ruling 31 forbids `tools/quality` from importing the framework, so those two
sides cannot share code at all and settle for sharing evidence. ⭐ **This seam has no such
wall.** The forbidden direction here runs one way — the merge path may not reach the FLOOR —
and both sides may reach a module that reaches neither. ⛔ **So the stronger instrument was
available and was taken: a shared table makes a divergence DETECTABLE, a shared module makes
it IMPOSSIBLE.** ⚠️ Measured rather than assumed: `tools/quality` already imports a sibling
top-level `tools` package in several modules, so the import is ordinary here.

⛔ **2. NOT a data file on disk**, which was the other obvious home. A JSON or markdown table
read at import is one more way for the merge gate to CRASH on a tree whose files are missing
or malformed — and turning that class of failure into a REFUSAL is the whole reason the gate
can be trusted on a broken tree. ⭐ Literals in a module are read by an import that already
had to succeed.

⛔ **3. The vocabulary renders an ALTERNATION, never a GRAMMAR.** `alternation` returns the
names and no `@`, no prefix and no anchor, because *where a reserved name may sit inside a
domain* is each caller's own policy — one parses a domain and tests its suffix, the other
searches free text. ⚠️ **This is what keeps the row from becoming a rewrite of either gate**,
and the first form of this row got it wrong; see Surprises.

⛔ **4. The floor's attribution trailer stays in the floor.** This project's commit trailer
is at a REAL domain and is exempt because every commit carries it, never because it
identifies nobody. ⭐ It is `ATTRIBUTION_ADDRESS` in the shapes arm. ⛔ Putting it in the
shared module would have told the MERGE PATH that a real domain is an office's line, which
is the widening the row names as building it wrong.

⛔ **5. The old names were REMOVED, not aliased.** `PLACEHOLDER_TLDS` and
`PLACEHOLDER_DOMAINS` are gone rather than kept pointing at the shared tuples: a second name
for one thing is where the next divergence starts.

⛔ **6. `ALLOWED_ADDRESS` is derived and the mirror asserts it.** It is what
`build_allowed_address()` returns, so re-typing the list into the floor goes red on a
comparison rather than silently rotting.

## Surprises

⛔ **1. MY FIRST FORM ANCHORED THE FLOOR'S GRAMMAR AND TURNED THE FLOOR RED — on another
office's negative fixture, which is how the real divergence got measured.** ⚠️ Sharing the
list tempted me to make the two sides agree on the MATCHING too, so I anchored the floor's
reserved branch at the end of the domain. ⛔ **That is a rewrite of a certified gate, and the
floor caught it**: `tests/studyforge/archive/test_scrub.py` deliberately holds an address at
a domain that is a reserved name followed by further labels, as a control proving the
framework's scrubber refuses it — and the floor's LOOSE grammar is exactly what keeps that
line legal under R7. ⭐ **Reverted: the grammar is byte-for-byte the one it replaced, and
only the LIST is shared.** ⚠️ The residual disagreement is real and is `W310/1` below rather
than a silence.

⭐ **The equivalence is MEASURED, not asserted.** The rebuilt pattern was compared against
the literal it replaced over a probe corpus, and the only inputs on which they differ are
three BARE reserved tokens — unreachable through this arm, because the email shape it filters
requires a dot in the domain. ⛔ No address the floor can actually reach changed verdict.

⛔ **2. THE PLANT CAUGHT A DEFECT THAT WAS LIVE IN MY OWN IMPLEMENTATION, and nothing else
would have.** The floor took the vocabulary with `from tools.reserved_addresses import
RESERVED_TLDS`, which binds the TUPLE OBJECT at import time — ⚠️ **a SNAPSHOT.** Every
agreement test still passed, because the two lists were equal; the floor had simply stopped
tracking the thing it was supposed to share. ⛔ **The plant went red on exactly that
assertion** — the merge path moved, the floor did not — and the fix is to read the vocabulary
THROUGH ITS MODULE. ⭐ *A divergence nobody can produce is not a guarded one*, stated as a
measurement instead of a maxim.

⛔ **3. MY FIRST NEGATIVE CONTROL WAS RULING 337'S DEFECT, in miniature.** The test asserting
that the shared module imports nothing read the file LINE BY LINE for lines beginning
`import` or `from` — and failed against the module's own DOCSTRING, on a sentence beginning
*"from importing the framework…"*. ⛔ **A claim about a module is not established by scanning
its text.** ⭐ Replaced with an `ast` parse, which is the property the claim actually is.
