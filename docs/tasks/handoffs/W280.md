## What landed

- **The split, as its own commit.** The seam was named before cutting: what the corpus root
  **holds**, asked of git and the plan, against what the manifest says each scanned file
  **is**. The walk (`Scan`, `source_files`, `repository_ignores`, `SKIP_DIRS`,
  `REPOSITORY_STORE`) moved byte for byte to the new module `validate.source.enumeration`.
  [`classification.py`](../../../src/studyforge/validate/source/classification.py) keeps the
  rule ids and `check_unclassified`, imports the walk in one direction, and re-exports each
  name importers read from it.
- **The export.** [`__init__.py`](../../../src/studyforge/validate/source/__init__.py) carries
  `REPOSITORY_STORE`, and
  [`inventory.py`](../../../src/studyforge/skills/reconnaissance/inventory.py) imports it from
  the package.
- **The guard.** [`test_init.py`](../../../tests/studyforge/validate/source/test_init.py) reads
  every module under `src/` for an import past `__all__`, whether a submodule or a name not on
  it. It asserts the survey is among the importers it read, and names each planted import.

## Decisions

- **The name, not a predicate.** The survey compares a directory name, and `_walk` asks the
  same name of a path's parts. A predicate would wrap one comparison. Reversible.
- **`classification` keeps an `__all__` of its re-exports**, so an importer that named them
  from that module still works, and a test pins each one as the same object.
- **The enumeration's tests moved to their mirror unchanged.** The two helpers they share with
  [`test_classification.py`](../../../tests/studyforge/validate/source/test_classification.py)
  live beside the walk they build, and that file imports them.
- **The guard sweeps `src/` only.** Tests name a submodule to monkeypatch a private, such as
  `shutil` or `_generated_output` in the enumeration module.

## Surprises

- Two onboarding tests patched `_generated_output` by the module that used to hold it. Pytest
  refuses to patch a missing attribute, so the move failed loudly rather than silently; the
  patches now follow the function.
