are `handoff-finding-id`, and the cause is structural rather than a format

it reads as *"scoped to a task this document does not declare"*.


⭐ **The fix already exists in the tree and it is `office handoff`'s shape:** that
kind declares `— <SCOPE>`, and `_check_office_identity` INVERTS the identity rule
so a scope that parses as a task ID is itself the finding. ⛔ **Ruling 176 governs

it, and this owes more.** ⚠️ **But it changes the declaration line of 77 existing
ruling records, which is editing records — so it is a ruling to make, not a patch
to apply, and it is why this is filed rather than fixed.**
