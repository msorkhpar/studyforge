## Decisions

- ⭐ **The documents are the branch's first commit and the tests the second.**
  §9's ordering applied to a reference rather than a skill: a document written
  after its checker is a document fitted to whatever the checker could reach.
  ⛔ `git log` is the evidence, which is `SK-07`'s bar and it is met.
- ⭐ **Two one-way checks, never an equality, wherever a closed set is
  involved.** Subset — the reference cannot teach a value the code does not
  have. Coverage — the code cannot own a value the reference never names.
  ⛔ Equality is satisfiable by shrinking either side, which is the whole of
  Ruling 30's argument arriving in a second place.
- ⭐ **Every command in the reference is spelled the way it runs**, so
  `python3 -m studyforge.validate` and not `studyforge validate`. ⛔ A reference
  whose reader will not read the spec must not hand them a command that does
  not exist, and a caveat above the command is what makes the divergence from
  the design documents a decision rather than an error. `SK-05/1`.
- ⭐ **The worked examples are the two shipped fixture corpora, and their
  manifests are quoted document-for-document rather than retyped.** ⛔ An
  example manifest written by hand agrees with nothing; one compared to the
  file it claims to be is checked on every run. ⚠️ It also means the *reader*
  can run every command on this page immediately, against material that is
  already in the checkout.
- ⚠️ **`docs/authoring/` registers with nothing, and that was checked rather
  than assumed.** The pointer walk, the personal-data sweep and
  `described_pathspecs()` all read `docs/` wholesale, so a new documentation
  directory is covered the moment it exists. ⛔ No list was edited.
- ⭐ **The markdown reader is fence-aware, and that is not tidiness** — see
  Surprises. It is the same use-versus-mention lesson `tools/quality/pointers.py`
  already records, arriving in a fourth instrument.
- ⚠️ **The personal-data assertion calls the repository's own gate**
  (`tools.quality.personal_data.shapes.shape_matches`) rather than restating
  its patterns. ⛔ A second copy of a gate is Ruling 20's measured failure, and
  a documentation directory is not a good place to make it a third time.
