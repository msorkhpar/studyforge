## Decisions

- ⭐ **`--site` stays as an override for one corpus.** `build --out` has no default, so a site
  can live outside its corpus, and only a named directory reaches it. `--site` names one
  directory and adds nothing beside the root's mount. `SK-03`'s `verbs.serve` spells
  `--site`, and it still parses.
- **The verb calls `discover` and `instance_of`, not `make_instance` whole.** That way an
  unbuilt corpus exits `1` before a socket exists, as the `--site` form does.
- **The manifest beside the directory is the rule**, not a list derived from discovery.
  `resolve` stays one function of the root and the disk, and nothing is configured.
