# W254 — handoff

**Kind:** task handoff — W254

**Status:** done

**What landed:** `studyforge.corpus.placement.bind(profile, containers)` returns a
`BoundProfile`. It is a `Profile` that answers `unit` for one corpus and carries
`collisions`, a tuple of `Collision(path, first, second)` where each side is a
`Claimant`. `Profile.unit`, `unit_stem` and `unit_page_name` take a keyword
`qualifier`. `plan`, the build (`generate.read_corpus`), `validate` (`paths.py`)
and `contents.build` all bind, so they place every unit the same way.

**Decisions:** the naming ruling is reversible and is recorded in
`src/studyforge/corpus/placement/bound.py`.

- A unit whose placed paths collide with another declared unit's gets its
  container's deepest address segment in front of its stem:
  `src/<segment>-unit-01-<title>.unit.html`. Other units keep their names.
- Cost: collision-free corpora are byte-identical. A name now depends on the
  corpus, though, so declaring a mirrored unit later renames the page it
  collides with.
- Anything the qualifier cannot separate is refused by name. `plan` exits 1
  with one refusal per path, the build raises `BuildError` (exit 2) before
  writing anything, and `validate` reports `duplicate-path`. Nothing wins by
  precedence.
- Rejected: naming from the origin's filename (R1, R4) and qualifying every
  unit (every `sibling` page would move).

**Surprises:** the floor's task-id pattern does not accept `INT09-5`. The row
will take its W id from register round 79.

**Findings:**

### W254/1 `[structural]` — spec §5's uniqueness claim is false for mirrored series

The spec says *"Names come from the unit's own numbering and title, so they
are unique"*. That does not hold for mirrored series in one directory. The
sentence should say that a collision is qualified by the container. Amending
the spec is the register's call.

### W254/2 `[local]` — a collision refusal shares `build`'s exit 2

A collision refusal exits 2 (`UNUSABLE`), like every other `BuildError`,
while the `cli/site` contract says 2 means the tool could not run at all. A
corpus defect sharing this code predates this row.

**For dependents:** `ISO-09` can re-take its archive. On ISO `8afdd5b` the
archive now validates with 0 `duplicate-path`, plans with 0 refusals, and
builds one page per unit with no `replace` line. The 5 mirrored pairs are named
`src/jpos-server-…` and `src/jpos-client-…`. Anything new that places a unit
must place it through a bound profile (`bind`), never through `profile_for`
alone.
