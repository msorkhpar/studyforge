## Findings

### W85/1 `[local]` — ⛔ my own guard was born vacuous, and the plant is what found it

⛔ **`import tools.quality.board.register as module` yields the FUNCTION
`register`, not the module**, because `tools/quality/board/__init__.py` does
`from tools.quality.board.register import register` and that rebinds the package
attribute. ⭐ **`vars()` of a function is `{}`, so the guard's reduction ran over
an empty population and passed with a `RULE_*` planted.**

- **Measured** by me at `96e8c95`, dev2 worktree, pinned image — **[measured]**.
  Expected `1 failed`; read `83 passed`. The diagnostic: `register RULE_*: []`
  while `package RULE_*:` listed all eight, with `grep -c '^RULE_STATE'` on
  `register.py` reading `1` at the same moment.
- ⭐ **Fixed in this diff** — `importlib.import_module`, plus
  `assert module.__name__ == "tools.quality.board.register"` so the subject
  cannot silently stop being a module. ⛔ **Recorded rather than quietly
  corrected: a guard that passes for the wrong reason is indistinguishable from
  a guard that passes.**
