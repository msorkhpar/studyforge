## Decisions

- ⭐ **The one home is `cli/serving.py`, not `test_serve_process.py` and not `tests/support.py`.**
  Importing from a test module would turn a collected test file into a library, along with its
  whole import graph. `support.py` holds helpers that know no verb, and the listening line is the
  `serve` verb's output. `serving.py` is already the shared module for the verb's tests.
- The store child prints one line, so its last line is its only line. Its plant suppresses that
  line (P3), and the test asserts that nothing follows it.
- The large-`stderr` child is a committed test, not just a plant, so the property stays guarded.

## Surprises

- ⚠️ P2 passes at runtime. The child blocks between its two lines, so the old mix never loses
  one. Only the guard catches it, just as W233's P4 needed the guard.
