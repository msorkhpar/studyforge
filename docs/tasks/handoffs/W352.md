## Decisions

- ⭐ **A fourth member of `VALID`, not a directory beside the declaration.** A corpus outside
  `VALID` is one no parametrized contract test opens, so every contract test in the suite now
  reads it — which is why it carries a plan golden.
- ⛔ **`test_record.py`'s *"exactly one valid document grades"* is now stated outside
  `runnable/`.** That rule exists so the graded state cannot quietly become the majority of a
  coverage set; a runner's fixture must grade, so the exception is named rather than counted,
  and the README says so where the rule is written.
- ⭐ **Graders are `check_*.py`.** Under the default `test_*.py` this repository's own run
  collects them — unit 2 fails and unit 4 errors on purpose. The corpus's `pytest.ini` names
  the pattern. ⛔ **A `conftest.py` ignoring the directory was refused**: the suite would import
  it and write its bytecode into the un-ignored fixture tree.
- ⛔ **Unit 4 fails to compile with `'break' outside loop`, never a missing colon.** Both are a
  `SyntaxError` and both stop the file running; only the second is a PARSE error, and five
  walkers in this suite `ast.parse` every `.py` under `tests/` — the first host run went RED in
  exactly those five (`W352/5`). The compiler-only error keeps them green and is pinned both ways.
- ⭐ **Every practice has the three sections `read_layout` requires**, and its starting code is
  the file as shipped — `test_blocks.py`'s sweep of every practice refused the first version.
- ⭐ **Unit 5, reading only, is one more than clause 1 lists.** It costs one lesson document and
  puts all three of §7's states in the one corpus `SF-44`'s acceptance names.
- ⭐ **The test runs the declared commands verbatim, except `python3` becomes the running
  interpreter**, so the grader runs under the pytest the suite already has.

## Surprises

- ⚠️ **The [`README.md`](../../../tests/fixtures/runnable/kata/README.md) of the container could not be `not_material`**: it matches `kata/*.md`,
  and `validate` refuses a file matched twice as `contested`. It is excluded with its reason,
  as `shared-origin/`'s is.
- ⚠️ **The first full host run went RED in six tests the fixture checks did not predict**: five
  `ast.parse` walkers (`W352/5`) and the practice-layout sweep, which `violations()` does not
  check (`W352/6`). Both were fixed in the fixture; no walker was edited.
- ⚠️ **The first image suite went RED on the bytecode plant alone**: the pinned image sets
  `PYTHONPYCACHEPREFIX` as well as `PYTHONDONTWRITEBYTECODE`, so the plant wrote its cache
  outside the copy. The plant now clears both, and passes with the prefix set on the host too.
