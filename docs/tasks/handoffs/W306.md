## Decisions

1. ⛔ **A FLOOR ARM, NOT A COMMAND UNDER `tools/` — and I did not inherit
   [`W302`](W302.md)'s conclusion.** ⭐ **Its reasons do not reach this check:** Ruling 80
   bars a floor check from reading UNTRACKED state and R10 wants the floor reproducible
   over arbitrary roots — ⚠️ **this arm reads TRACKED FILES ONLY: the row files and the
   convention. No git, no branch, no daemon, no clock.** ⛔ **And the decisive half is
   that the floor is ALREADY IN THE MERGE PATH** — `tools/mergegate.py` runs it as a
   gate — so a floor arm is run by the mint path without anybody remembering to, which is
   the whole complaint of this row. ⭐ A command would have to be INVOKED, and *a human
   ran the right command* is exactly the assurance `PO-94` found wanting.
2. ⛔ **The predicate is PARSED, not typed** (above). The row's own clause: the command in
   the convention is the authority; this makes the mint path run it, never restate it.
3. ⭐ **The population is every file under `docs/tasks/rows/`, minus the declared
   exemption** — not *live rows only*. ⚠️ A closed row's Ruling 270 stub carries an
   anchored archive pointer by construction, so it passes on its own merits rather than by
   being skipped, and *born with a pointer* is a property of the FILE rather than of a state
   cell that moves later.
4. ⛔ **Composed into `check_board` rather than registered in `tools.quality.CHECKS`.**
   ⭐ The board package is where the row files are already read, and the standing SPLIT
   condition on `board/__init__.py` is DISCHARGED (`W129`/`W130`/`W132`), so composing an
   arm there is legal and needs no split. ⚠️ **`register.py`'s and `verdict.py`'s
   conditions are LIVE and I touched neither.**
5. ⛔ **An empty population is never a pass** — three ways: no row files at all yields
   nothing (the floor's standing split over arbitrary roots, with the presence half
   asserted against the live tree), an unreadable clause is a finding, and the denominator
   is printed on every run.
