## ⛔ The argument, and it is decided by what the tree already does

⚠️ **Both behaviours are defensible in isolation, which is why the author could
not settle it.** The tie is broken by four facts, none of them a preference:

1. ⭐ **`PersonalDataLeak` is deliberately not a `ValueError` and deliberately
   not in any package's family.** `archive.scrub` designed it that way. **A
   translation undoes that design one module at a time.**
2. ⛔ **A package family exists so a caller catches one type *per item* and
   continues** — that is what it is *for*. So a translated leak is logged as
   *"that unit did not build"*, the walk finishes, and the report is green about
   the one thing R7 exists to make loud. **R7 is a HARD FAIL rule failing open.**
3. ⭐ **Two packages already state the exception in their own contract**, so the
   counter-argument — *"a promise with one exception is not one"* — has a known,
   cheap answer: **say what crosses.** A contract that names what crosses it is
   better than one that swallows it.
4. ⛔ **It is already load-bearing, and I measured it rather than reasoning about
   it.**
