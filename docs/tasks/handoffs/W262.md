## Decisions

- ⭐ **`board-detail`, not a new code.** An argument with no home is that code's meaning already, for a `W` subject. Reversible: a new code in `bijection.py` and the package surface.
- ⭐ **A HEADING whose first token is the id defines a task.** At `8f59ed9` every task-id heading in the epics is `###`, and no id is headed twice.
- ⛔ **The lookup never stands down.** In a tree with no epics, every In-flight epic task is named, because none is defined, and the reading prints the population. So `W161`'s PASSES test now plants the epics that define its subjects.
