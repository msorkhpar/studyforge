## Decisions

⛔ **1. One notice for the unanswered, silent when inhabited — not a line per check.** The row
forbids a disclosure printed on every green run, and `0 = 0` read as a clean bill only arises
where a population is empty (Rulings 48, 191). ⭐ Measured on this branch: it prints nothing
over this repository.

⛔ **2. Paired checks are REGISTERED, not re-printed.** Their own notices already print their
denominators in every state; a second line would be noise. ⭐ Registering the pairing is what
lets the floor refuse an unanswered new check, and the tests read the notices' actual output
rather than trusting the pairing.

⛔ **3. The populations are EXTRACTED from the checks, never restated.** A disclosure over a
second walk could say *inhabited* over a verdict reached on an empty one — `W307`'s decision 2,
applied to every arm.

⛔ **4. `check_personal_data`'s identifier arm is answered in two halves without touching
`identity.py`.** `identity_notice` says whether a VALUE was there to compare; nothing said
whether any FILE was. The files half is `config.text_files`, which the arm already calls, so
it is registered here by reference.

⭐ **5. No convention document was edited, and no ruling minted** — Rulings 48 and 191 already
carry the ground; the contract lives in the module it describes.
