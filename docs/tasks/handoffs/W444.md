## Decisions

1. ⭐ **"Authored" is the `generated` provenance on the document's own `exercise` record.**
   - **It is intrinsic.** It is a field of the archive document, and `validate.corpus` has
     already parsed and validated it (R5's pairing included) before any check runs. No ordinal,
     path or directory is consulted.
   - **It is the same trigger as the exercise arm.** `validate.exercises` holds every `generated`
     practice to a bundle and a cleared gate record at `Places(address, variant, unit,
     ordinal)`. So a document this check leaves out is one that arm must account for.
     `GENERATED` is imported from `validate.exercises`, so the trigger has one spelling.
   - **It matches the spec.** Spec §7's table makes every authored exercise `generated`
     (*code, no tests* and *neither*), and says an authored exercise on a *code and tests*
     source never borrows the derived `bundled` label.
2. ⛔ **Why not "a bundle exists".** A bundle's place is computed from the document's address,
   unit and ordinal, so asking the disk for it would decide by position. That is exactly what
   the row forbids. It would also be wrong later: `E08` says `EX-04`'s source-derived (`bundled`)
   exercises will emit through the bundle too (`W444/2`).
3. ⭐ **The whole document is left out, including any `lesson` blocks the adapter passes to
   `emit`.** Those blocks copy the unit's lesson material, and that material is already counted
   through the unit's lesson document. If an adapter put source material only into an authored
   practice, the lesson bucket would read short, so the failure stays loud.
4. ⚠️ **One catch site: `except ExerciseError`, with `# pragma: no cover`.** It follows the shape
   of `validate.exercises._authored`. `studyforge.exercise` exports no `RAISES` and has no floor
   in `tests/test_raises_convention.py`'s `REACH`, so no floor moves. That test is GREEN. On an
   unreadable record the document is counted, not skipped, so the fallback is the stricter
   reading.
5. ⭐ **The new tests are in a file of their own**, because `test_completeness.py` is already
   close to the 600-line test bound. `completeness.py` stays inside R11's 400 lines.
