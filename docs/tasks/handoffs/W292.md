## Decisions

⛔ **1. The test types CATEGORY WORDS, never file names — so the three get no
`AUDITED_AGAINST`.** The row forbids a second copy of these vocabularies, and the
statement is what decides whether that costs anything: its words name CATEGORIES, so a
member added inside a category (`.dockerignore` into `IGNORE_NAMES`) leaves the
statement TRUE, and the test is correctly GREEN — measured. ⭐ What makes a statement
FALSE is a member the skills type, a member the refusal does not reach, a category
nobody states, or an emptied vocabulary, and each of those goes RED.

⚠️ **2. The one direction this cannot catch is a DROP, and it is `W292/1` below rather
than a silence.** It is the price of clause 1 as written, and the asymmetry with
`ROOT_DOCUMENTATION` — which has a copy from W281 and is caught both ways — is exactly
the cost of that copy, stated so whoever rules on it has both readings.

⛔ **3. A dotted name counts wherever it appears; a bare stem still only in upper case
or in a code span.** `.gitignore` is never an English word, so any occurrence in a skill
is a copy, and the leading dot is what keeps `git status` in the onboarding skill from
reading as one. ⭐ The looser rule for stems is W281's and its ground (`W281/1`, the verb
*copying*) is unchanged.

⛔ **4. `VCS_DIRECTORIES` is declared at DEPTH (`nested/{name}/config`).** A directory is
not a file to edit; what a manifest would actually declare is a file inside one, and
that is also the claim `edits.py` makes for this vocabulary — *at any depth*.

## Surprises

⚠️ **1. Emptying a vocabulary reddens TWO tests, not one**, because both walkers assert
inhabitance. ⭐ Left as it is: Ruling 191 is a property of each walker, not of the suite.

⛔ **2. The plants that mattered most were the ones against the REFUSAL, not the
vocabulary.** A vocabulary and a statement can both be perfect while the branch that
connects them reads a literal — and that plant is invisible to every test that only
reads names. It is the reason this row asserts refusal per name rather than membership.
