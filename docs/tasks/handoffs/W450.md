## The test, and why it takes this shape

- ⛔ **It uses the real `serve` process**, `python3 -m studyforge.cli serve <root> --site <site>
  --port 0`, over a `depth2` site that `studyforge build` wrote. It does not use `served.py`'s
  in-process app, and it never writes a header itself. The browser applies the policy that the
  verb sends.
- ⭐ **It asks every face to load** (`FontFace.load()` on each of `document.fonts`). A face the
  page does not use stays `unloaded` under any policy, so a reading of only the used faces would
  pass over a blocked italic. Each `FontFace` comes from the stylesheet, so `font-src` governs it.
- ⭐ **The expected set is derived from `faces.FACES`**, not typed as seven.
- ⛔ **No violation from any directive.** A `securitypolicyviolation` listener is installed with
  `Page.addScriptToEvaluateOnNewDocument`, before the document exists.
