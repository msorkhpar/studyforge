## Decisions

- **`prose` is the variant word.** It is the one [`examples.md`](../../authoring/examples.md) and [`corpus.md`](../../authoring/corpus.md) use for a single-variant corpus, which answers ISO's Q9 convention worry. It is reversible and asked about in the report.
- **The slug rule is SF-01's**, imported, not the proposal's collision-only `slugify`.
- **Exact paths only where the wildcard would catch the record.** Every other directory keeps its wildcard.
- **The empty `title` and the empty header are the same defect** (the unresolved `.`), so they are fixed here too.

## Surprises

- ⚠️ The census found a third empty-name field, `title`, which is reached only when there is no record. ISO has a record, so ISO never showed it.
