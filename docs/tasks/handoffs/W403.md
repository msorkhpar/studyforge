## What landed

`Task | Component | Framework half | Sibling half`. The four roles are read from the HEADER and
never from a position, so the columns may be renamed or reordered; a value is a CODE SPAN, and
`none`, `—` or a blank cell declares NOTHING, which is a refusal rather than an empty column.

⭐ **The reading.** For each declared task the framework half must be reached by the release
branch of this checkout, and the sibling half must be reached by that component's **pinned
commit in `workspace.json`** — resolved in the component, never from its `HEAD`. Refusals name
WHICH half and WHICH component:

| the state | the answer |

## Decisions

- ⭐ **The declaration is a FILE BESIDE THE BOARD, `docs/tasks/CROSSREPO.md`, and that is
  MEASURED rather than preferred.** At `778e618a` the board is **112,337 bytes against 112,416
  allowed — 79 bytes of headroom**, and the smallest well-formed block (markers, declaring
  header, one row) is an order of magnitude more. ⛔ Raising the term is refused by Ruling 271:
  `board-size`'s allowance grows with the register ids and the delimited observation and
  scheduled rows, and a new block earns nothing in any of the three. ⚠️ **The register asked for
  the form to land in [`board.md`](../../conventions/board.md), and it did** — what moved is the
  DATA's home, and the cost (a reader of the board alone does not see the file) is stated in
  `crossrepo.py` and in the convention.
- ⭐ **ABSENT is NOT ANSWERABLE and a DECLARED, EMPTY block is a real answer** — `W111`'s
  distinction one table over. Otherwise deleting the file would make the instrument go quiet,
  which is the shape of the defect this row closes.
- ⭐ **The PRESENCE half is a test of THIS repository**, following
  `test_bijection.py::test_this_repository_has_a_board_with_a_DELIMITED_register`: the floor may
  not demand a board of an arbitrary root, so the *it must be there* half lives in
  `tools/tests/quality/board/` and reads the file's bytes, never git.
- ⭐ **No floor arm was added.** The form rule is enforced inside `judge` (a row declaring one
  half is REFUTED) because that is where the other arms of the same reading live; adding a
  `CHECKS` code would have put half of one rule on the floor and half in `corroborate`.
- ⚠️ **`workspace_root` and `DEV_CONTAINER` are imported from `tools/workspace/__main__.py`
  rather than respelled** — one home for *where the siblings are* — and `tools/workspace/**` was
  deliberately not edited because `W402` and `W404` are holding it this wave (finding 5).
