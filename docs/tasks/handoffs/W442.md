## Decisions

1. ⭐ **The address is a constant, not a resolution.** From the corpus's own checkout, which is
   what every reader and every clone has, the workspace's sibling layout (R18,
   [`docs/conventions/workspace.md`](../../conventions/workspace.md): a `sibling` is `<workspace>/<name>`) always gives
   `../studyforge`. `framework_from(main_checkout(root))` would give the same answer by
   construction, so there is nothing to compute. ⛔ Computing it would keep a code path through
   which the running checkout could reach the output bytes again, and that path is the defect
   this row removes.
2. ⚠️ **`W321`'s hazard is now handled by the prose, not by the address.** A reader standing IN a
   linked worktree who runs the fenced commands there points `git -C ../studyforge` at whatever
   sits beside the worktree. The document now says the address and the commands are relative to
   **the main checkout's root**. ⛔ The alternative, a per-checkout address, is exactly the
   non-reproducibility this row removes.
3. ⚠️ **`onboard(root=)` is kept, and it changes no output byte.** Removing it would break
   `reonboard.py` and `tests/test_authoring_exercises.py`, and dev2 (`W443`) is editing both
   concurrently. See `W442/1`.
4. ⭐ **The `framework` parameter stays on the pure renderers** (`pin.stub`,
   `artifacts.reader_document`) with `SIBLING` as its default. `onboard` never passes it. The
   byte-identity test guards that, and the plant below shows the test catches a regression.

## Surprises

- ⭐ **This row reverses `W321`, it does not refine it.** `W321` deliberately made the address
  depend on the checkout, so that the commands would run from inside a worktree. `W442` shows that
  the same choice made the output depend on where it was generated. `W321`'s tests were rewritten,
  not kept.
- ⭐ **The stub wording changed as well** (`from that main checkout's root.`), so the regenerate
  below moves the stubs on every corpus, not only on one generated from a worktree.
- ⭐ The source files in the package got shorter, and none is near the 400-line ceiling.
