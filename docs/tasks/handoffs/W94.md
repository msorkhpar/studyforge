## ⛔ The derivation, run before anything was cut

⚠️ **The row's instrument is a syntactic proxy and says so:** *raises inside a loop* cannot see
a refusal that stops at its first witness because its **caller** iterates. ⭐ **So the population
was re-derived across call boundaries**, by an `ast` walk that resolves calls inside the package
and propagates loop-reach through them. It ships as the row's own test, in
[`test_init.py`](../../../tests/studyforge/skills/delivery/test_init.py), so it cannot rot into
a figure quoted in prose.

**What the walk does.** For every function in `src/studyforge/skills/delivery/`, it marks each
`raise <X>Refused` as

- **lexical** — inside a `for`, `while` or comprehension in its own body;
- **caught** — every in-package call site of the enclosing function sits inside a `try`, so a
  caller gathers the refusal and it is control flow rather than a shipped refusal;
- **caller** — the enclosing function is reachable from a loop through in-package calls, which
  is the class the function-local instrument is blind to;
- **clear** — no loop reaches it.

**What the walk CANNOT see, stated rather than implied.**

1. ⚠️ **Calls are resolved by NAME.** `milestone.lines()` reaches every `lines` in the package,
   including `Backlog.lines`. The reach is therefore **over-approximated**, which can add a
   member to the residue and can never hide one.
2. ⚠️ **"Reachable from a loop" is itself a proxy.** A refusal that already gathers its whole
   population is correct wherever it sits, and no walk over syntax can tell. ⭐ That is why each
   residue member carries the reason it is not a first-witness refusal, and why the residue is
   asserted to be **exactly** that set rather than merely to be small.
3. ⛔ **Only this package.** A refusal raised in `src/studyforge/` elsewhere is outside the row.

**The reading, three refs, one instrument** (the subject of the row, so its figures are quoted;
`c18df98c` is round 49's own ref and is here as the corroboration, not as a claim about today):

```text
                                        c18df98c    2e6e83b   this tip
refusal raises in the package                 60         64         60
  lexical (raised inside its own loop)         5          7          0
  caller  (first witness by a caller's loop)   8          8          5
  caught  (gathered by a caller in this pkg)   1          1          3
  clear   (no loop reaches it)                46         48         52
```

⭐ **The `5` reproduces round 49's function-local reading EXACTLY**, which is what says the two
instruments agree where they can both see; the `8` beside it is what that one could not see.

## What landed

- **`refusal.one_or_all`.** One reason is the **identity**, so every refusal that was already
  right reads byte for byte as it did. Several are rendered `<count> refusals, and every one of
  them is named — a; b; c`. ⛔ It adds no vocabulary of its own: a reason arrives already written
  by the check that found it, so no path or value enters a message that did not carry one (R7).
- **`backlog.checked`** gathers. `_check_framework` and `_check_corpus` now **return** their
  reasons instead of raising, because the `for milestone … for task …` loop is in `checked` —
  which is the member the row said was real and invisible, arriving from the caller's loop.
- **`backlog.critical_path`** refuses every cycle at once. `_cyclic` closes each task's
  dependencies over the plan until nothing grows and gives back every task that reaches itself,
  so two disjoint cycles are one refusal counting four tasks. ⭐ The walk beneath it therefore
  carries no cycle guard: it runs over a graph already known to be acyclic.
- **`capability.Index.of`** gathers, and the two checks are independent `if`s: a capability that
  is both declared twice and unplaceable contributes two reasons rather than one.
- **`epics.read_epic`** gathers every unreadable row in a document. **`epics.read_epics`** gathers
  every unreadable document, which is where `capability_index` used to stop at the first of
  thirteen through a generator expression.

## Decisions

- **The message form is `<count> refusals, and every one of them is named — …`**, count first,
  because the count is the cost a first-witness refusal hides. Reversible in one constant.
- **A single reason is the identity.** Anything else would have moved the 52 refusals that were
  already correct and every test pinning them. This is asserted directly, five times.
- **A count, never new names.** Where a refusal named nothing (`_check_corpus`, the cycle), the
  gathered form counts; where it already named ids (`Index.of`, `read_epic`), the gathered form
  names all of them. ⛔ R7: no value enters a message that did not already carry one.
- **`seen.setdefault` in `Index.of`**, so a third declaration of an id is reported against the
  first, not against the second. With one duplicate pair the message is unchanged.
- **`read_epic` stays public and per-document.** `read_epics` is the population around it, which
  keeps the single-document call the unit and makes the boundary explicit.
- **The derivation lives in `test_init.py`**, the package-contract mirror, because Ruling 188 is a
  property of the package and not of one module. It is not in `tools/quality/`: that is another
  office's live surface this wave.
