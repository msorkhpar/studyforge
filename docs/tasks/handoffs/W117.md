## Decisions

- ⭐ **It binds an AUTHOR, not a BUILD.** The line is written by whoever writes a page that
  commands a module the framework does not own. Nothing in `src/` or `tools/` reads it, and no
  built output changes with it. Its one reader is a suite test over documents. So it does not go
  in `module-structure.md`, whose subject is how code is built (R11–R13, R17). No convention
  document had a section for pages, so this row adds a short one.
- **Not a rename.** Before any change I checked the frozen-name rule (round 52). The name is
  cited by `W74.md`, the CTO's round 52 record, `BOARD-ARCHIVE.md`, `BOARD.md` and
  `rows/W117.md`. Both spellings are byte-identical to what they were at `a8c4738`.
- **The check never types the spelling.** It reads the spelling from the home, and it sweeps for
  the label without its bold markers. That form also finds the reader's regex-escaped copy.

  are records. A page label that does not contain the words *consumer side* is not seen. Both
