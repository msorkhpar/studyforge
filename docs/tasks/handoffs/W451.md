## The design

**Route:** `POST /api/v1/quiz/<corpus>/<practice key>/<question>=<option>/<question>=<option>…`.
There is no body, because `serve.app` drains a request body and discards it. `=` is outside both
`QUIZ_ID` and the practice-key alphabet, so the answers are the trailing segments that carry one,
and a segment splits in only one way. A repeated question, a bad id or a segment without `=` after
the first answer gets `400`. Other answers: `404` for an unknown corpus or practice, `409` for a
practice that is not a quiz, `422` for a document that fails validation, `403` for `Origin: null`
(a file page), and `405` for a `GET`. `serve.app`'s gate refuses a foreign `Host`, a cross-site
`Sec-Fetch-Site` and a foreign `Origin` before the route runs.

**Response** (`quiz-verdict`, `no-store`):

```json
{"api": 1, "resource": "quiz-verdict", "corpus": "…", "practice": "…",
 "asked": 2, "right": 1, "complete": false,
 "questions": [{"id": "q-1", "answered": true, "chosen": "a", "correct": true, "says": "…"},
               {"id": "q-2", "answered": false, "chosen": null, "correct": false, "says": ""}]}
```

**Where the key is read:** the unit's generated document, which `CorpusContent` builds per request
from the corpus's archive on disk. The archive practice document is where the bundle's quiz record
lands. It is the same document the run route reads a command from. The grading rule is
`exercise.quiz.grade`, the framework's one rule. ⛔ No model, network or container is involved, and
the route does not import `execute`.

## Decisions

- ⭐ **One request grades the WHOLE quiz, not one answer.** Completion is a property of the whole
  quiz. With every chosen answer in one request, `grade` decides `complete` once, in Python. A
  per-answer route would make the page add up the verdicts itself. That would be a second
  spelling of the completion rule, in a file that cannot import the first.
- ⭐ **A wrong answer reveals its own sentence, never the key.** *"With explanation if needed"* is
  met by the chosen option's sentence, which gate `Q4` guarantees exists. It says why THAT option
  is or is not right. If the key were named on the first wrong choice, the reader would be told
  the answer instead of taught, and a quiz has no attempt limit. ⚠️ Stated plainly: with a few
  options a reader can still find the key by trying each one. The ruling keeps the key out of the
  PAGE. It does not make the key unguessable, and the code says so.
- ⭐ **POST, a writer**, although nothing is recorded. Grading is an act, and a prefetch must never
  take it. That matches how the run namespace treats its acts.
- ⭐ **The client lives in `run-client.js`**, published as `studyforge.quiz`, not under `.run`
  (a quiz produces no run). The serving process inserts exactly one client script into a page. A
  second insertion would give a built page a second way to learn that it is served, and would
  widen `app`/`assets`' `client=` seam.
- ⭐ **The route has its own 12-line `workspace_of`** and does not import `routes.run`'s. That
  module imports `execute`, `test_init.py` pins who may import it, and dev2 is working in
  `run.py`. See `W451/3`.
- ⭐ **Completion is not persisted.** The page shows it from the verdict, and the server records
  nothing. The progress store holds run outcomes. Both are asserted. Recording a quiz's completion
  in the reader's own state (browser-side, like read marks) is a decision the old
  `practice-quiz.js` already left to "the row that takes it", and this row did not take it.
- ⭐ **§11.0 and the authoring guide were amended too**, although the brief named §7 §7, `AX-05`
  and `AX-06`. Each stated the superseded claim (*"no server"*, *"the page shows the reader the
  answer"*), and the spec cannot be left saying the opposite of itself. Both are amended in
  place and dated.

## Findings

### W451/1 `[structural]`: the key is still SERVED, by two routes a page never loads

⛔ The ruling's clause (no page and no asset a page loads) holds and is tested. ⚠️ **But a served
origin still hands out the key to anyone who asks for it by URL:**

- `GET /api/v1/content/units/<unit>`: the content namespace answers the unit's generated
  document verbatim, and a quiz's `workspace` in it carries `correct` and `says`;
- the static mount serves any non-dot file under the root, which includes
  `archive/<container>/raw/<variant>/unit-NN/practice-M.json`.

⭐ Neither is loaded by a page, and the reader's disk holds the archive anyway. Whether to redact
the content document, or refuse `archive/` on the static mount (the `private=` seam exists), is
the register's decision. The content namespace's contract is to serve the document unchanged,
so this row did not change it.

### W451/2: `AX-11` and `AX-09` still read the old stance

`AX-11` says *"A quiz practice completes on all-correct answers and not otherwise, **offline**"*,
and `AX-09`'s Acceptance says *"A quiz page shows questions, grades them"*. After the ruling a quiz
grades only over a served origin. Neither row is this row's, so both are left for the register
to amend.

### W451/3: two readers of a practice section

`serve.routes.run.workspace_of` and `serve.routes.quiz.workspace_of` are the same 12-line read.
The shared one could live in a module that imports neither `execute` nor a route, with `run`
delegating to it. That was not done here, because dev2 is working in `run.py`.

### W451/4: `shutdown()` before `serve_forever()` is a hang, not a failure

`test_run.py`'s `test_instance_of_registers_run_as_the_one_writer_and_it_runs`, and any test with
the same shape, turns an assertion failure into a hang that lasts the suite's whole timeout. The
remedy is to start the thread before asserting, or to `server_close()` without `shutdown()` when
no thread ran.

### W451/5: a `--site` seam with no run namespace would show the file sentence while served

The quiz client ships in the run client. A `--site` serve whose namespaces were replaced to carry
no `run` (`W386`) gets no client, so its quiz page shows *"This page was opened as a file"* while
it is actually served. That is harmless, because such a serve cannot grade anyway, but the
sentence is false there. The code panel has the same property today.
