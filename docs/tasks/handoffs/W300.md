## Decisions

### ⛔ RULED: the tension in Ruling 101 is answered STRUCTURALLY, not only by ordering

⚠️ `W299/1` says a surface pin must land before any spelling is fixed, because a sweep
defined over submodule imports releases a name the moment somebody corrects the spelling.
⭐ **Ordering alone would make that safe once.** ⛔ **Reading BOTH spellings makes it safe
permanently**: the same question is asked of `from studyforge.validate.corpus import Held`
and `from studyforge.validate import Held`, so the name stays held whichever spelling the
tree settles on. ⚠️ The ordering constraint was honoured anyway, in the commits, because
it is what the row was dispatched under and history is where that is checkable.

### ⛔ RULED: the 44 are DECLARED, not fixed, and the ground is a blast radius

⭐ The row permits a declared exemption and forbids a silent one. ⛔ Exporting these names
would edit seven packages' published surfaces, and for three of them there is no surface
to add to — `archive`, `narrate` and `serve.routes` declare no `__all__` at all. ⚠️ **One
package's five names cost [`W299`](W299.md) a whole row and a collision ruling**; seven
packages' worth is not something a sweep row may do in passing, and the brief's *not a
second spelling of an existing surface* forbids the shortcut.

### ⛔ RULED: Ruling 101's FIRST row is PRINTED and failed nowhere

⚠️ A name that IS exported and is taken by the submodule spelling is a one-line deviation,
and there are 39 of them across 12 packages at this ref. ⛔ Failing them would turn the
floor red on landed code no office has been assigned — FND-07's *a red run for a condition
nobody may be failed for is a red run that gets muted*. ⭐ So the census enumerates them
with their denominator, and the pin is what makes them safe for a later row to fix.

### ⚠️ `deviations.py` is a second module because the table breached R11

⭐ MEASURED: `surfaces.py` reached 423 of the 400 ceiling when the declaration landed in
it, and the floor caught it. ⛔ Ruling 261 — a ceiling is not a budget — so the remedy is
`reach.py`'s split and not a size exception: the READING stays with the check, the
DECLARATION becomes a sibling, and the seam runs one way.

## Surprises

- ⛔ **THE PIN ARM IS ALREADY CLEAN, AND THAT IS THE ROW'S REAL SHAPE.** Every deviation
  in this tree is in the MODULE spelling; nothing takes an undeclared name straight from a
  package. ⚠️ So the pin fails nothing today and is a guard for the future — which makes
  its non-vacuity the whole question, and why the mirror pins the population the clean
  bill was taken over rather than asserting an empty list and stopping.
- ⛔ **The population was understated by more than double, and the cause is structural.**
  Both prior readings asked *which names are off a surface* of packages that HAVE one.
  ⭐ A package that declares no `__all__` at all cannot be measured that way, and three
  such packages hold most of the population. ⚠️ `W298/1` warned the count would be wrong
  and it was right for a reason nobody had named.
- ⚠️ **`studyforge.serve` declares a surface of one name while five names are taken from
  its modules.** A surface that exists in name only reads, to any instrument, exactly like
  a surface that is being reached past — and only the census tells the two apart.
- ⛔ **The floor caught this row's own size breach before any gate did**, which is the
  check-yourself property working: `tools/` is a scan root, so the instrument that
  enforces R11 is held to R11.

## For dependents

- ⭐ **Sharing a name between packages now has one rule and the floor enforces it**: put
  it on the owning package's `__all__` and import it from the package. ⛔ Both spellings
  are checked, so neither is a way around the other.
- ⛔ **Adding an entry to `deviations.DECLARED` to quiet a red is declaring a defect, not
  fixing one** — [`W199`](W199.md)'s rule, inherited unchanged. Each entry owes a ground,
  and the mirror fails an entry that carries none.
- ⛔ **Fixing a declared deviation means DELETING its entry in the same commit.** The
  stale arm reds otherwise and names the entry, because the population is closed at its ref.
- ⭐ **Whoever takes `W300/3` (or `W299/3`): the spellings are safe to correct now.**
  Changing `from studyforge.validate.corpus import Held` to
  `from studyforge.validate import Held` keeps the name held by the pin arm, and the
  census's backlog shrinks by one line. ⚠️ Do not also drop the name from `__all__` in the
  same breath — that is the one edit the pin exists to refuse.
- ⚠️ **Whoever takes a row in this wave: read `W300/1` before your first commit.** The
  identity the dispatch names will red the floor on documents you never touched, and the
