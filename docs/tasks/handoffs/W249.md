## Decisions

- **The record's title, not git's common directory.** A common directory still differs between two clones, and an archive has no git.
- **Exclusion follows SF-02's own definition:** prose an include would read. A file no include reads is proposed as `not_material`, so no file name is special (R1).
- **The open marker is `null`, never a string.** SF-02 refuses `null`, so an unsettled draft cannot pass as settled.
- **Onboarding's record decides its footprint.** Without it, a re-survey of an onboarded corpus proposes the reader document it wrote (`artifacts.READER_DOC`) and the scaffold's directory, and `promote` refuses both.

- ⚠️ `promote` did not pair a drafted `not_material` reason, although the brief says it does. An open `why` reached the parser and was refused one glob at a time (`W249/1`).
