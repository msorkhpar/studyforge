## Decisions

⭐ **Both the net and the containment, and the third option refused.**

1. ⛔ **Refused: teaching the harness which callables are writers.** It needs a
   name list, it rots, and it *shrinks* a census whose own floor
   (`LEAST_CALLABLES_PROBED`) exists to stop the coverage quietly going to zero.
2. ⭐ **The net — detect, not prevent.** It knows nothing about writers, so it
   covers the whole suite rather than one harness, and it would have caught both
   instances without being told they existed.
3. ⭐ **The containment — the census chdirs out of the tree.** It earns its place
   *beside* the net because `SF-17/11`'s damage was cross-contamination **during**
   the run: a detector speaking afterwards reports the stray file and leaves the
   mystery red in the other module standing. ⚠️ **Two mechanisms for two
   different failure times**, not two attempts at the same one.

⛔ **A DELTA and never "the tree is clean".** The absolute reading is red for
every contributor with edits in flight, ⭐ **and a check that is red by default
gets switched off** — that is the argument, and it outlives this check.

⛔ **Blind spots, stated in the module and asserted in its tests:** a path
`.gitignore` covers (`--ignored` is not passed — `__pycache__/` moves every run,
so a snapshot including it is never equal to another one), and any write outside
the repository. `git` unable to answer returns `None` and prints **NOT CHECKED**,
never the pass reading (Ruling 191). ⭐ One exemption, and it is read from the
**declaration** rather than named here: `STUDYFORGE_VISUAL_CAPTURES`, the
variable `tests/visual/conftest.py` itself reads.

and the escape is not the one it names.** Measured at `abee048` with an audit

`(out: Path, note: str)` — which is what `SF-17/11` was and what the new
directed test plants. ⚠️ **One path argument escapes by accident; two is the
trap.**
