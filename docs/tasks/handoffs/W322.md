## What landed

### One producer, asked three times

`skills.adapter.Layout` computes a unit's overlay address in one place. Each of the three sites
now asks it:

- **`test_membership.py`** writes the overlay with `layout.content(ADDRESS, 1)` — the row's own
  remedy, one call. Three more composed paths in the same file went the same way while the file
  was open, because each is the same defect in the same module: the container map it corrupts is
  `Layout(root).container_map(ADDRESS)`, the good document it copies is
  `Layout(root).document(ADDRESS, VARIANT, 1, "lesson", 1)`, and the manifest it rewrites is
  `Layout(root).manifest`.
- **`media.py`** asks `addresses.unit_files_in(container_dir, document["unit"])` and imports no
  path segment of its own.
- **`addresses.py`** walks `overlays_in(root)`, compares a unit directory with `unit_named()`,
  and reads its archive root and its map filename from the framework.

⛔ **What stays spelled, and it is not an exemption.** A path *no layout produces* — a stray
planted where nothing reads it, a document copied to the wrong depth — has no producer to ask,
and spelling it is the whole subject of the test that plants it. Those literals are left alone
and the instrument is built not to see them.

### The glob, which is the half that needed a mechanism

A glob wants a pattern, and `Layout` produces paths. `overlay_glob()` therefore computes a real
overlay path — at a real address and the first ordinal, so `Address` and `unit_name` both refuse
a placeholder — takes the part *below* the container directory, and replaces the digits
`unit_name` filled in with a wildcard:

    units/unit-01/content.json   ->   units/unit-*/content.json

⭐ **All three segments arrive from their owners** — `units/` is placement's, `unit-NN` is
`unit_name`'s, the filename is the overlay contract's — and the single thing this module knows
about the shape is that an ordinal renders as digits. ⚠️ **It is `Layout.archive_tree`'s trick,
used for the same reason:** a drawing computed from the layout cannot drift from it.

⛔ **Computed per call, never at import.** A module constant would freeze the derivation at
import time, and the tests below move the framework's constants at run time to prove the sites
follow.

### The failure that hides, and the assertion that ends it

⛔ **A derived pattern is not enough on its own, and this is the row's real product.** A walk
whose pattern followed a moved filename would find **nothing** — and report nothing, which reads
exactly like a corpus with no overlay to check. ⭐ So `overlays_in` is separated from
`check_overlays` and asserted directly: the shipped fixture's overlay is found, and the expected
path is `Layout`'s own rather than a second spelling.

⚠️ **Measured on the base tree** (`release/m0-foundations` at `6541eec`, host, Python 3.14):
with `CONTENT_FILENAME` moved, the whole of `tests/test_fixture_consistency.py` is **GREEN,
exit 0** — the overlay walk kept reading a filename the framework no longer mints, and nothing
said so. That is plant P7 below, and it is the row's claim, measured.

### Two repairs that came with the line they were on

1. ⛔ **`f"unit-{overlay.get('unit'):02d}"` RAISED** rather than yielding, for an overlay that
   declares no unit or a unit that is not an int — `TypeError` for the first, `ValueError` for
   the second, inside a generator whose whole contract is to *yield* findings about documents
   somebody else wrote. `unit_named()` returns `None` there instead, so such an overlay is
   refused by name and the walk carries on.
2. ⭐ The `"prose"` literals in `test_membership.py` are now the module's own `VARIANT`. The
   variant is the corpus's **data**, not the layout's geography; declaring it once is what makes
   the distinction visible beside the paths that are the layout's.

## Decisions

1. ⛔ **The instrument reads *joins*, not spellings** — a string literal that is an operand of
   `/`, or an argument to `glob`/`rglob`/`joinpath`. ⚠️ `container.get("units")` reads a JSON key
   and mints no directory; `x / "units"` makes one. ⭐ **This is `W298`'s discriminator, reused
   for the reason it was invented:** `units` is a key as well as a segment, and a census that
   cannot tell them apart teaches the next office to edit the census. Its limit is stated in the
   function's own docstring: `os.path.join`, `"/".join` and f-strings are not seen — and an
   f-string is deliberately how these sites spell the places that have no producer.
2. ⛔ **The scan is over the three sites the row named, listed by path** — not a glob over
   `tests/`. A row measured three files; an instrument that widened itself would be asserting
   something nobody agreed to, and the fourth site below is a finding rather than a patch.
3. ⭐ **The shared derivation lives in `addresses.py` and `media.py` imports it.** Putting it in
   both would have replaced one duplicated join with another. `addresses` is the module whose
   stated question is *where a thing sits*, `media` already depended on this package, and the
   direction creates no cycle.
4. ⛔ **`check_container`'s archive root is now `Layout(root).archive`, and that is a deliberate
   trade recorded in finding W322/1.** Its sibling walker `containers_in` still spells `archive`,
   so the two disagree under a moved `ARCHIVE_DIRNAME` and the disagreement surfaces as a
   `ValueError` rather than as a named finding. ⚠️ **It is still strictly better than the base**,
   where the same plant was silently green — but the clean repair is the fourth site, and that is
   one row over.

## For dependents

- ⭐ **Ask, do not spell.** A test that needs an archive address asks `Layout`; a test that needs
  a *pattern* asks `addresses.overlay_glob()` or derives its own the same way. Adding a fourth
  site to `SITES` in `tests/test_archive_addressing.py` is how a new test file joins the
  obligation.
- ⛔ **`tests/fixture_checks/addresses.py` now exports geography.** `unit_files_in(container_dir,
  unit)` is the one answer to *where does this unit's own material sit*, given the container
  directory a fixture check is handed; `overlays_in(root)` is the one walk over authored
  overlays. Neither is re-exported from the package `__init__` — import them from the module, as
  `tests/fixture_checks/shape.py`'s consumers already do.
- ⚠️ **The instrument will red on a literal it should not**, in one case: a test that must name a
  path the framework abandoned — checking a migration, say — and that builds it with `/`. ⭐ The
  answer is an f-string with a comment saying why there is no producer to ask, which is the form
  `test_membership.py`'s stray plants already use; the answer is **not** widening `OWNED`.
- ⛔ **Do not move `overlay_glob()` back to a module constant.** It is a function so that a
  framework constant moved at run time reaches it, which is how clause 2 is asserted in process.
