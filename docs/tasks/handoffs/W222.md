## Decisions

- **`audio_dir` takes the placement answer, not the declarations.** Keeping its old five arguments plus a `label` would leave two derivations that agree only while every caller passes every argument, and that agreement by discipline was the defect. The signature change breaks any outside caller: `git grep` finds none beyond the two changed here.
- **`heard` keeps its `source` parameter**, now unused, so `generate.clips` and the page pass keep one call shape. See `W222/1`.
- **The rewritten `SF-38` test now asserts the fix.** It used to assert that a labelled unit's page names a gap; it now asserts that the page plays and names none.

## Surprises

- The page side needed no change: `generate/units.py` already asked `unit_location` with the label. Only narrate's side and the build's read had diverged.
