## Decisions

- ⭐ **A test, not a floor rule.** The check imports `studyforge` for two jobs. It compares the
  callee with `fields.optional_origin` by identity, so a local function that only shares the
  name counts as a second reader. It also resolves imported constants such as `UNIT_KEYS` by
  value. `tools/quality` deliberately never imports what it checks (see `mirror.py`), and
  W107's tree check set the precedent of a test.
- **The class comes from what the site does with the value, never from a list of spellings**
  (Ruling 65). A value handed straight to the reader needs no declaration. A bare read is a
  second reader. A store, a delete, an `assert` comparison or a dict-display value is a
  writer's act. A writer declaration does not exempt a bare read. A `parser` declaration
  counts only inside `corpus/container/`.
- **A dict display is not an access**, because it cannot read. Declaring each one would give
  an exemption list that grows with every fixture.
