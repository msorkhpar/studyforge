## Decisions

- **An id is the board's declared vocabulary**: `register.identifiers` plus
  `bijection.EPIC_TASK` (W161). Not backtick spans, which count markup. A subject in neither
  counts `0` ids and is still a row.
- **`1 rows`, not `1 row`.** The plural is fixed so the shape stays one pattern for a parser.
  Reversible.
- **The unit of each count, as landed:** header `observation rows` = rows; `checkouts on a
  branch` = checkouts; `started register cells` = register rows (one state cell each),
  unchanged; the reading's five counts = rows or started rows; `n of m rows REFUTED` = rows;
  `n rows NOT ANSWERABLE` = rows. ⭐ The only count in ids is the new one on the fold lines.

## Surprises

  `len` or `sum` over rows.
