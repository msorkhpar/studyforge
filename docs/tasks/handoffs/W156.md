## Decisions

- ⭐ **Clause 3: the finding's input is `Owns` ALONE.** The row's hazard is *nowhere to write*.
  `Context` is a READ, so it is printed as a second arm and never fails the floor. That was
  measured before deciding: both of its members are sound.
- ⛔ **An earlier-step creator with no edge is a finding too**, which is wider than clause 2's
  literal wording. The README's widened rule (a later step may START once an earlier one is
  saturated) means step order no longer proves the creator lands first. At `accceaf` no row is
  caught by the wider half alone; P1 and P4 show it fires.
- **The plan's graph, not the disk.** A component is a sibling in `workspace.json` whatever its
  status. A component some row creates is walked. One nobody creates is pre-existing when it is
  pinned `present`, and a finding when it is not. That keeps the `NS` members as a live, silent
  control.
- **The creator** is the root claimant placed earliest in the README's document order, which is
  the decided milestone order.
