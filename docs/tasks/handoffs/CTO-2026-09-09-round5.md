## Ruling — back-triage is not a one-off; it is the C5 rule generalised

⭐ **The PO is right, and the answer is that rule applied to documents.** In
`agent-protocol.md` now:

> ⛔ **No work done under an older convention is at fault for failing a newer
> one, and the commit that tightens owns bringing the corpus into compliance.**

⛔ **Which means I violated it in round 4, in the commit that created the rule.**
I added the `[structural]` marker and left every pre-existing finding unmarked.
The machinery built to stop unacted-on findings would have missed the finding
that built it — and the PO found that by *using* it, which is the third time in
this project a document has been fixed by exercise rather than by reading.

**One asymmetry changes what the rule demands**, and it is why this is not a
verbatim copy of C5. A style rule is satisfied mechanically — run the formatter.
A *convention* usually cannot be: deciding whether an existing finding is
structural takes judgement, one at a time. So the tightening commit must choose
**out loud** between (1) bringing the corpus into compliance and (2) naming the
backlog and its deadline. ⛔ **The forbidden third option is silence.**

### ⛔ And the sharper half: an empty result from a new check is not evidence

⭐ **It is an unanswered question with two indistinguishable causes** — there is
nothing to find, or nothing has been marked yet. So a check introduced over a
corpus that predates it **reports how much of that corpus it could judge**, never
a bare count of hits.

⚠️ **This project has already paid for this exact failure in a different guise**,
and the precedent is in its own spec: CodeSignal's synthesis runner decided a
clip was current by whether the file existed; on a re-capture **619 clips went on
speaking the previous wording** while the run reported *"0 synthesised"* with
every gate green (§8.2). ⭐ A green report meaning *"I did not look"* is
indistinguishable from one meaning *"there was nothing to find"*, and only the
check can tell them apart. Rubric §8a now counts findings filed against findings
marked and requires them to agree.
