## Decisions

- **`\A…\Z`, not `fullmatch`.** `execute/commands.py` calls
  `SAFE_SEGMENT.match(name)` itself. If the fix were `fullmatch` inside
  `safety.py`, that caller would still be open, or would need its own edit.
  Fixing the anchor in the pattern closes the hole for every caller, including
  ones not written yet, however they call it. `execute/commands.py` needed
  no edit.
- **`\r` and `\r\n` are asserted even though `$` already refused them.** `$`
  matches only before `\n`, and `\r` is not in either set. So those two
  parametrisations pass under both anchors. They guard the fix; they do not
  tell the two anchors apart. The `\n` cases do that (see the plant below).

**Whole-value gates that admit a trailing `\n`.** Each was probed at this
branch's tip:

1. `W434/1` `[local]` `src/studyforge/archive/document.py:153`: `ISO_DATE = ^\d{4}-\d{2}-\d{2}$`,
   used by `_require_iso_date` as the whole check on a manifest's `ingested`.
   **`ISO_DATE.match("2026-09-22\n")` is truthy**, so an `ingested` value with a
   trailing newline is accepted and written into the archive. This is the
   closest match to W434's defect and is a candidate for a new row.
2. `W434/2` `[local]` `src/studyforge/validate/structure.py:44` and
   `src/studyforge/validate/corpus.py:55`: `UNIT_DIR = ^unit-(\d{2,})$`,
   matched against a directory name. **`UNIT_DIR.match("unit-01\n")` is
   truthy**, so a unit directory whose name ends in a newline passes the
   identity check (`structure.py:123`) and gets a unit number (`corpus.py:224`).
   This is lower severity: it is a validator's identity check, not a security
   boundary. POSIX does allow such a name, though.
3. `W434/3` `[local]` `src/studyforge/validate/structure.py:45`:
   `ARCHIVE_FILE = ^(lesson|practice)-(\d+)\.json$` has the same shape and also
   admits `"lesson-1.json\n"`. **It cannot be reached today**, because the walk
   that feeds it is `rglob("*.json")`, and a name ending in `\n` does not match
   that glob. It is the same defect waiting for a different walk.
4. `W434/4` `[structural]` **Nothing stops a new whole-value gate from being
   anchored `$`.** This row and `W434/1` to `W434/3` show the same
   mistake in four modules. None of them was caught by a gate; the row

## For dependents

- `SAFE_SEGMENT` and `SAFE_ARGUMENT` now match a whole value however they are
  called. A caller does not need `fullmatch`, and it should not add its own
  newline check.
- If you write a new whole-value gate, anchor it `\A…\Z`. A pattern that
  another module imports must never be anchored `$`.
