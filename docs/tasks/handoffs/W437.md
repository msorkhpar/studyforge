### ⛔ Where a unit's existing practices are read from

⭐ **The archive, not the bundles directory.** A source's own practice is an archive document,
`<archive>/<address>/raw/<variant>/unit-NN/practice-M.json`, with `kind` and `ordinal` recorded
inside it. `exercises/` holds only what this skill authored. ⭐ **The reader is the one a build
uses**: `unit.builder.read`, which loads every document through `archive.document.load` (the
version check and the personal-data gate included) and answers `Material.of_kind("practice")`.
The directory comes from `skills.adapter.Layout.unit_dir`, which `generate.declarations` also
uses. ⛔ **No second reader and no second path spelling was written.** The container map's
`practices` count was NOT used: it is a declaration, which is exactly what the row says is a
second copy that can go stale.

## Decisions

1. ⛔ **`carried` is a required argument of `author_page`, not a default of `()`.** A default
   would let a caller that never read the archive number from 1 again, which is the defect.
   The row's rule is *read, never declared*, and only `author_corpus` calls `author_page`
   outside the tests.
2. ⭐ **The guard is its own function, `require_after_carried`, so it can be tested without a
   broken loop.** Otherwise it could only ever be reached through a plant. It names the first
   repeated practice, and it hands a gap to `bundle.require_no_gap`, which already words that
   refusal. It does not word it a second time.
3. ⛔ **A unit whose archived practices are not `1..n` is refused.** An authored exercise cannot
   be numbered after a hole, and closing the hole would renumber the source's practice.
4. ⚠️ **`loop.py` carries `PRACTICE = "practice"`.** `archive.document.KINDS` is a plain tuple
   with no named member, so there was nothing to import by name. See `W437/3`.

## Surprises

⚠️ **On the first corpus, the collision is not visible in any file this skill writes.** The
source's `practice-1` lives in the archive, and its reader workspace lives under a directory
the corpus chose (`practice/bitmap/`). The authored `practice-1` would have gone to
`exercises/…/practice-1/` and `practice/iso-fundamentals/prose/unit-02/practice-1/`, so
`commit`'s R3 check had nothing to compare and would have written it without complaint. ⛔ The
collision would only have surfaced when the adapter emitted a second `practice-1.json`. That is
why the guard reads ordinals and not files.
