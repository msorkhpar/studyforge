## Decisions

- **A collision is exact glob equality**, the same test the manifest's own reader uses for a repeated glob. An overlapping but different glob (`ingest/read.py` against `ingest/**`) passes through; the manifest accepts both.
- **Refused even when both reasons are identical.** A person retyping a generated declaration is the retyping R19 forbids, and the manifest refuses the repeat whatever the reasons say.
- **The glob is quoted, a reason never is.** A colliding glob equals a generated one, so it cannot be a path from somebody's machine (R7).
- **Malformed drafted entries pass through** to `_refuse_unreadable`, so they are refused in the manifest's words, not in a second copy of its rules.
- **`content` is built before the version is chosen**, so a content refusal now precedes a version refusal on a draft that has both.
