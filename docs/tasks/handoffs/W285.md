## The seam, named before the cut

[`creators.py`](../../../tools/quality/creators.py) stood at its R11 ceiling, so it split
first, in a commit of its own. The seam is **parse against judge**, as `W275/1` suggests:

- **the parse** became the new module `tools.quality.plan_parse`. It holds what the plan's
  texts DECLARE, with no verdict: `Row`, `declarations`, `rows`, `_block`, `placement`,
  `aliases`, `components`, `preamble_component`, `resolve`, the patterns, `MILESTONE_ID`,
  `RULE_MILESTONE`, and the path constants;
- **the judge** stays in `creators.py`: `Member`, `Graph`, `graph`, the edge closure, the
  verdict, `read`, `check_owns_before_creator` and `creator_census`.

`creators` imports the parse in one direction and re-exports every name its importers read.

## What landed

- **The split, as a pure move.** Code lines moved byte for byte, and the parse's two tests
  moved to their mirror. A test pins each re-exported name as the same object, and the
  "typed once" test now counts the new module.
- **Clause 1.** [`board/delivery.py`](../../../tools/quality/board/delivery.py) builds its
  section and closed-row patterns from `creators.MILESTONE_ID`. The compiled patterns are
  identical to the ones it typed before.
- **Clause 2.** `sibling_owned` reads `creators.declarations` and returns each refused row
  beside the column. `read` names each one as a NOT READ reason of the sibling column, so the
  row is in neither column and is never skipped in silence.

## Decisions

- **A refused row makes the delivery reading exit `2`.** The sibling column is short a row,
  which is the same kind of fact as a column that cannot be read at all, and that already exits
  `2`. No figure moves the exit. Reversible: drop the reason from `unread` and print it as a
  note instead.
- **`delivery.py` imports from `creators`, not `plan_parse`**, as the row says. The new module
  stays an implementation detail behind `creators`.
- **`sibling_owned` returns a pair**, the same shape as `declarations`, so no second call can
  forget the refusals. Its one caller and its tests follow.
- **`rows()` is unchanged in signature and never raises.**
