  [`docs/tasks/README.md`](../README.md); this refuses a number before a `POPULATIONS` noun in Python prose.
  Disjoint by surface and by noun.
- **The date is SENTENCE-scoped.** Paragraph-scoped, it admitted the `reach.py` gap copy whose
  paragraph's ref measured a line count.

  `458` reading that way. A longer span is not blanked, so a stray tick cannot hide a paragraph.
- **A sibling module**, for `W150`'s reason: `citations.py` is near R11's ceiling and `reach.py`
  carries the split condition.
