## Decisions

- ⭐ **I extended the command rather than writing only a clause.** The brief's plants need output that can turn RED. Reversible: remove the `W165` block from the module, its tests, and the rubric clause.
- ⛔ **The command reads a report and never takes one.** A member's time in the census's own report is its SKIP time, not its cost. A cost needs the gate open, and this command only removes variables.
- ⭐ **Clause 2 is its own clause, not an amendment to [Ruling 326](../../conventions/review-rubric.md#ruling-326-a-reading-is-quoted-with-its-environment-or-it-is-not-a-measurement-and-green-names-the-environment-that-produced-it).** 326 binds every reading. An amendment would carry the spread half to every timing, and that is the row's MUST-NOT. A ruled section is also a record (Ruling 106). Reversible: move the bullet under 326.
- ⚠️ **Both halves bind only a gated population.** Clause 1's selection half reads as if it binds every cost figure. But a whole-suite timing names `tests/` and is correct work, so `owed()` returns nothing for an ungated figure (`W165/2`).

## Surprises
