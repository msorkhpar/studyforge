## Decisions

- ⭐ **Excluded by PATH, never by basename or directory.** `render/assets/` holds authored and
  vendored files side by side. A directory exclusion would let the next authored file put
  there pass unread. A basename exclusion would let an authored `prism.js` anywhere else pass.
- ⭐ **`VENDORED`, and why each:** `prism.js` (Prism, minified, under `prism.LICENSE`),
  `plyr.js` and `plyr.css` (Plyr, minified, under `plyr.LICENSE`). `plyr.svg` is not listed
  because `.svg` is not an authored suffix.
- ⭐ **Templates count.** The row says "every authored source file the framework ships", so
  `.html` under `src/` is read along with stylesheets and scripts.
- ⛔ **Markdown does not count.** A skill such as [`SKILL.md`](../../../src/studyforge/skills/adapter/SKILL.md) is a document the framework ships, not a module,
  and R11 is a ceiling on modules. See `W367/2`.
- ⛔ **`src/` only.** The row names the files the framework ships. `tools/` and `tests/` are not
  shipped.
- ⛔ **No `Size exception:` opt-out for a non-Python file.** It has no docstring to carry one,
  and a comment near the top is not the contract R11's marker is. A test shows the marker in
  a CSS comment does not open the gate.

## Surprises
