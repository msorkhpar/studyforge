## Decisions

- ⭐ **The reader stays in `validate/blocks.py`, widened, and is renamed.** The harness calls it through its module, as [`W263`](W263.md) set up. A name that says `list` would have lied. Reversible.
- **The `document` rule id, as `W263` chose.** Its row already says *malformed*, so no count moves.
- ⚠️ **A value is described, never quoted (R7)**, as `W263`'s messages are: *"has type a str"*. The harness used to print the type string itself (`W282/3`).
- **An unknown type is named and read no further.** No row exists to read its keys or its contents against.
