## Decisions

- ⭐ **Redact one surface and refuse the other.** The content namespace ANSWERS A DOCUMENT
  whose contract is the unit's shape, so it keeps the shape and drops only the two fields. The
  questions and each option's words are what the page already shows. The static mount answers
  FILES byte for byte, so a file is never edited on its way out. A file that carries the key is
  refused with the same `404` as every other refusal there.
- ⭐ **Content-aware, not path-based.** A path rule (`archive/`, `exercises/`) was rejected for
  three reasons, each of them measured:
  1. The ISO corpus's own handoff `docs/studyforge/handoffs/ISO-25.md` quotes the quiz JSON,
     both key and sentences. No path rule names it.
  2. Refusing `archive/` would stop serving code practices' documents. The row requires those
     "exactly as today".
  3. A page's references were read: ISO pages load `/<page>`, `.studyforge/assets/page.css`,
     `page.js` and the run client, plus `data:` fonts. None of them is under `archive/` or
     `exercises/`, so the content rule needs no allow-list of what a page loads.
- ⭐ **The sentences come from the reader the quiz route grades with** (`CorpusContent.unit`), so
  what is withheld is exactly what is graded. They are cached against a stamp of the unit
  directories, so a quiz edited while the instance serves is withheld from its next request
  (tested).
- ⭐ **The key is read structurally as well as by sentence.** With only sentences, a bundle whose
  sentences drifted from the archive would be served. With only structure, `ISO-25.md` style
  prose that quotes a sentence would be served.
- ⭐ **Unknown types are read too.** `.java`, `.xml`, an editor's `quiz.json~` and a `.yaml` copy
  are all served as `application/octet-stream`, and before this row they were streamed unread.
- ⚠️ **Fail closed.** A page from a build before `W451` carries `data-practice-correct` and its
  sentences, so it answers `404` until the corpus is rebuilt. See *For dependents* for the order
  that makes this invisible.
- ⭐ **`MIN_WORDS = 4`.** A sentence shorter than that is not searched for. Otherwise a `says` of
  *"Right."* would withhold every page that happens to say it.
- ⚠️ **A text's `304` now costs a read, not one `stat`**, because withholding is decided before
  any validator. Plant 7 shows why: a validator honoured first answers a withheld file `304`.

## Findings

### W452/1 `[structural]`: the editor iframe serves the whole corpus, bundle included

⛔ **This process no longer hands out the key. The embedded code-server can.** The editor
container is up over the corpus's own files, so a reader with that editor open can open
`exercises/…/tests/quiz.json` in it. That is another process on another origin, outside `serve/`,
and the ruling is about what the SITE serves. Whether the editor's mount should exclude quiz
bundles (or `archive/`) is the register's decision. The run route's output has the same
property: a command's output is whatever a corpus program prints.

### W452/2 `[local]`: `exercise/quiz/__init__.py` still states the pre-`W451` stance

Its docstring says *"The key and the per-option sentences ship inside the practice document… the
reading is identical over `file://` and over a served origin"* and *"The honest design shows the
reader the answer once they have answered."* After `W451` and this row, both are false. This row
does not own that module.

### W452/3 `[local]`: the residuals `carries` cannot read

1. A key written in prose with no structure (*"the answer is b"*).
2. A sentence under `MIN_WORDS`.
3. A compressed archive holding a bundle.
4. An unknown-type file over `GATE_MAX_BYTES`.
5. A quiz of a corpus the instance did not discover.

⛔ The code says so in `serve.withheld`'s docstring, and none of these five exists in the ISO
corpus today (read above).

### W452/4 `[local]`: a sentence repeated verbatim in a lesson withholds that lesson's page

Fail-closed has a cost: if an author writes a `says` that is word for word a sentence of the
lesson prose, the lesson page carries it and answers `404`. No such case exists in ISO (every
page answered as before). An authoring gate (`AX-06`'s Q-gates) could refuse such a `says`. That
gate is not this row's.
