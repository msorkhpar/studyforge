which is what a *finished* unit looks like, so the panel is emitted by a state no
fixture is in. ⭐ `_outstanding()` adds one to the archived count rather than typing

a box with the box within it. ⛔ Named rather than filtered by a rule, and
`test_site` asserts it is a member of the population, so the exclusion cannot
become a silent hole if the table is rewritten.

**6. `STYLESHEET_DAMAGE` is one mapping and it sits low in the module.** ⛔ The
first draft had a branch in `build()` and a tuple in `_damage_page()`, and a
damage added to one and not the other produces a tree that is **not damaged at
all** — a control that passes. ⭐ One declaration, below the two functions it

## What I refused, and why

**1. ⛔ RULING 236 STOPPED THE ASSERTION I WANTED TO WRITE, and this is the
refusal the brief asked about by name.** The natural form of `W98`'s own check is
*"every chrome region resolves a column of N px"* — and I measured the number,
**840.00 px**, identically on all seven pages. ⛔ **I did not write it.** A
resolved width is a text-layout output, `fonts-liberation` arrives unconstrained
from the base image's Debian snapshot (`W36/5`, `CTO-55/5`), and a px figure in a
test is a **recorded value with an undeclared input behind it and a margin of
zero** — precisely the clause that binds `W98` by name.

⭐ **What I wrote instead is an EQUALITY between two measurements taken in one
run**: each region's column against `main#content`'s, in the same layout, under
the same font. ⛔ **A font change moves both sides together, so the assertion is
invariant under any font the image ships** — and it still fails the moment a
region resolves a measure of its own, which the `column` control proves on 7 of 7
pages. ⚠️ **So this row needed no font pin and did not wait for one**, which is
why `W124`'s placement ahead of me changed nothing I delivered.

⛔ **What `W124` DOES still gate, named rather than left as a silence:** nothing
anywhere asserts that the reading column *is* the measure the palette declares.
The equality catches one region resolving a column of its own; it cannot catch
every region, the reading surface included, resolving the wrong one because

resolved `ch` width against a recorded px value, it is **blocked on `W124`**, and
`tests/visual/test_site.py`'s docstring says so where the check would go.

**2. ⛔ I refused to TIGHTEN either of the two font-dependent thresholds, and
