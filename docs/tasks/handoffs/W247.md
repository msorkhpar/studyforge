## Decisions

- **The dash is folded into `_MILESTONE` as an alternative, not a second regex.** [`capability.py`](../../../src/studyforge/skills/delivery/capability.py) is held to 400 lines, and a separate `_CANCELLED` put it at 405.
- **The refusal cites the heading's line and the row id, never the declaration text**, the same as the existing "carries no id" refusal. The row id has already matched a strict pattern, so quoting it is safe.
- **This is a behaviour change on purpose.** Before, any unreadable declaration was silently cancelled. Now it is refused. The live population has none: the index regenerates byte-identical at `900a52f`.
