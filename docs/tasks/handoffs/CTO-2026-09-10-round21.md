## Decisions

### ⛔ Item 1 — the `__pycache__` taint is real, and the control ran negatively four ways

⭐ **The reporter's mechanism is correct and I reproduced it before trusting the
remedy**, because six instances in this project of a check that could not fail
reporting success made a seventh the likelier outcome than a fix.

CPython validates a `.pyc` against the source's **mtime in whole seconds** and
the source's **size in bytes**. A same-size mutation written inside the same
second as the cached compile is never compiled. **Measured, host, Python
3.14.4** — source on disk versus what the interpreter ran:

```
source=62  observed=62   OK
source=58  observed=62   STALE  <-- taint
source=62  observed=62   OK
source=99  observed=62   STALE  <-- taint
```

⛔ **It fails in both directions, and which one you get depends on what warmed
the cache.** Warmed from the original, every same-size mutant reports
**SURVIVED** — pessimistic. ⛔ **Warmed from a *failing* mutant, every one
reports KILLED**, and that is the flattering direction the report warned about.
I built it:

```
MUTANT A = 58 (cache cold; this compile populates the pyc)   test saw 58 -> KILLED
restore ORIGINAL (same second)                               test saw 58 -> KILLED   <-- impossible
MUTANT B = 99 (same second, same size)                       test saw 58 -> KILLED   <-- B never ran
```

⭐ **The middle line is the free negative control the sweep never had:** the
restored original cannot be killed, so a sweep whose baseline reports `KILLED`
is discarded. That is Ruling 70's operative clause.

⚠️ **The window is not theoretical here.** The inner loop —
`pytest -q tests/test_gate_coverage.py` — is **0.30 s**, so three mutants fit
inside one second. Same-second is the normal case in this repository.

#### ⭐ Ruling 40 is necessary and **not sufficient**, which is the finding I did not expect

`docker/dev/Dockerfile:147` sets `PYTHONDONTWRITEBYTECODE=1`, as an `ENV` with
no `ENTRYPOINT`, so it covers every command. **In the pinned image the taint
cannot be generated** — same four mutations, and the cache count:

```
PYTHONDONTWRITEBYTECODE = 1
  source=62 observed=62 OK   source=58 observed=58 OK
  source=62 observed=62 OK   source=99 observed=99 OK
  __pycache__ dirs created: NONE
```

⛔ **But that variable disables *writing*, not *reading*, and the checkout is
bind-mounted.** A cache a **host** run left in the tree is still read inside the
container. Measured, same stale `.pyc`, three readers:

```
host, no purge                      DWB=<unset>  observed=62   (source says 58)
host, re-run                        DWB=<unset>  observed=62
CONTAINER, same bind-mounted pyc    DWB=1        observed=62   <-- inherited
```

⭐ **The container cannot create this taint; it can inherit one.** That is a
genuine narrowing of Ruling 40 and it is now written into §4c.

**Three remedies, each proved, each proved negatively:**

| remedy | result | its own control |
|---|---|---|
| purge `__pycache__` | `observed=58` correct | re-created staleness → `62`, twice |
| `PYTHONPYCACHEPREFIX` outside the tree | `observed=58` correct | same command without it → `62` |
| pinned image **and** a cold tree | correct, no caches written | warm tree → `62` |

The first run of the sweep above pointed at a test path that does not exist. It

```
W25      62 -> 58        exit=4  KILLED                               | no tests ran in 0.00s

```

⛔ **Two mutants reported KILLED by a run in which no test executed** — the exact
failure I was ruling on, committed inside the ruling, within ten minutes of
writing that six had preceded it. ⭐ **The per-file BASELINE row is the only
reason I saw it**, which is why Ruling 70 makes that row mandatory rather than
advisory.

### ⭐ `W28` uses Python 3.14 syntax that reads as a Python 2 error

`src/studyforge/validate/source.py` contains `except OSError,
subprocess.SubprocessError:` — unparenthesised, which was a `SyntaxError` for
the whole of Python 3 until **PEP 758** allowed it in 3.14. I read it as a
defect, then checked: `requires-python = ">=3.14"` and the image is pinned
`python:3.14-slim`. ⛔ **Legal, in range, and `ast.parse` confirms it.** Recorded
below as a nit, not a finding — but the next reviewer will stop on it too.

### ⭐ `PO-19/7` was reported broader than it is, and nobody had measured the instrument

The claim was that §8a cannot be documented in the directory it polices. Against
the shipped reader rather than the rubric's grep, **three of the four
mention-shapes already do not count** (fence, table cell, prose with a lead
word). Only a line *opening* with the marker still does. See Ruling 73.

## Findings

### CTO-21/1 `[structural]` The dev image should isolate bytecode, not merely decline to write it

`PYTHONDONTWRITEBYTECODE=1` stops the container polluting a contributor's tree —
its stated purpose, and it does that — ⛔ **but it leaves the container reading
whatever bytecode a host run left in the bind mount, which I measured.** Adding
`PYTHONPYCACHEPREFIX` pointing outside `/workspace` makes the container's
isolation from host bytecode **structural rather than procedural**, and I proved
the mechanism redirects reads as well as writes.

⛔ **Scheduled**, not ruled: it is a one-line change to `docker/dev/Dockerfile`
with a test in `tests/docker/test_dev_image.py`, and ⛔ **I do not write
framework code.** Owner: framework agent, sized as a `W`-row. ⚠️ It is not
urgent — the purge step in Ruling 70 covers the same hole procedurally today.

### CTO-21/2 `[structural]` The rubric's §8a grep over-counts precisely the documents that discuss §8a

The hand-runnable grep counts raw occurrences; the floor counts finding *lines*
and is fence-, lead- and table-aware. ⛔ **A reviewer who reports the grep's
number inflates exactly the handoffs that document this clause**, which is how
`PO-19/7` arrived. ⭐ **Ruled — Ruling 73, landed in `review-rubric.md` §8a**,
which now states the divergence and the three escapes.

### CTO-21/3 `[local]` `W28`'s new syntax will cost every future reader a lookup

`except OSError, subprocess.SubprocessError:` is legal on the pinned 3.14 and
gratuitously novel; the parenthesised form is universally understood and costs
two characters. ⛔ **Not a finding against the change** — it is in range, it
passes `ruff`, and rewriting merged-quality code over taste is not a reviewer's
call. Recorded so the next reviewer does not repeat my stop.
