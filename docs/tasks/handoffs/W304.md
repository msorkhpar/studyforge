## Decisions

### ⛔ 1. The row is REPORTED, not implemented — and the document is not edited to agree

⛔ **Doing what the row asked would have REPLACED `FORM 1` with `FORM 2`, deleting one of
the two forms [Ruling 241](../../conventions/review-rubric.md#ruling-241-cto-round-55-the-warning-above-is-replaced-by-a-form-because-it-failed-three-offices-in-three-rounds)
mints.** ⚠️ **That is precisely the failure the row itself warns about one paragraph
earlier for the counter-example** — *the page would get WORSE while every gate stayed
green* — ⭐ **and the row did not notice that its own target was the blessed form.**

⭐ [`agent-protocol.md`](../../conventions/agent-protocol.md) is explicit: implement the
half you judge right, **say so with the measurement that decides it, and leave the
document alone.** ⛔ **The measurement is the four-row table above, and it is not an
argument.**

### ⭐ 2. The fix taken is the one the READING produced, and it is inside the grant

⛔ **The row's clause 1 grants the form: *"by whatever form Ruling 241 already
blesses"*.** ⭐ **`FORM 1` IS such a form, already blessed and already correct, so the
reading chose a third remedy — bind it rather than replace it** — which is
Ruling 268's grant-decided-by-the-reading, and the readings that killed the offered
remedy are printed above.

### ⛔ 3. The instrument is BOUNDED to two blocks, and the bound is MEASURED rather than asserted

⛔ **The row forbids a lint rule over shell snippets in prose, and it is right to.**
⭐ **Measured at my ref: the document contains THREE pipeline-exit sites, and a
document-wide rule would file a finding against CORRECT material** —
[`W143`](../../conventions/review-rubric.md#w143-a-plant-is-restored-from-a-copy-taken-before-it-per-file-and-never-with-git-checkout)'s
restore loop reads `$?` after a `|` that lives inside a command substitution, where the
status is `cp`'s and is right as written. ⛔ **So the check reads only the two blocks
Ruling 241 owns.**

### ⛔ 4. The counter-example is exempt BY A PROPERTY, never by a line number

⛔ **The brief exempted it by LINE, and a line number is not a property a test can
hold.** ⭐ **The exemption asserted here is the comment the line carries about itself**,
so the exemption survives every re-wrap — ⚠️ **and the test fails if somebody deletes the
wrongness, which is the direction nothing previously guarded.**

### ⭐ 5. Where the test lives, and what it did NOT cost

⛔ **Not `tests/docker/`**, where `W301`'s sibling lives: that module's contract is
`docker/dev/check`'s own header, and that directory keeps a CLOSED register of readers of
`docker/dev/` text. ⚠️ **Putting a rubric-only check there would have cost a register
entry and a count bump for a file it never reads.** ⭐ **It sits at `tests/` root, the
idiom `test_acceptance_clauses.py` already uses for a convention document.** ⛔ **No
register, count or bound moved.**

- ⭐ **The defect this row was minted from is real and now closed in the only direction
  that was open**: nothing prevented `set -o pipefail` being dropped, moved below the
  pipeline, or split into another fence, and the snippet would have stayed green in every
