## What landed

### The footprint weighs every clip the record locates

- `recorded.recorded_clips(base)` reads `.studyforge/narration.json` through
  `narrate.synth.read_state` and returns two things. The first is every path
  `narrate.synth.located` gives for an entry's current clip and for each of its superseded
  clips, relative to the root and sorted by the posix string. The second is every clip it
  cannot locate, as `Unlocated(speech_id, filename)`.
  - An absent record locates nothing, and that is not a refusal.
  - An unreadable record raises `MediaError`. Its message quotes no path.
  - A blank filename records no clip, so nothing is weighed and nothing is named.
  - A filename that is not one file name is named by speech id, and the name is not echoed.
- `footprint.measure_directories` walks the directories it is handed, as before. It then adds
  every located clip that is a file on disk, under the same relative-path key the walk uses.
  A clip that both reach is counted once. `measure` goes through it, so both public readings
  widen together.
- A located clip that is **not** on disk weighs nothing and is not named. It is not an
  under-count. A file in a removed unit's directory that the record does **not** locate is not
  reached: the record locates, and the walk is not widened to guess.
- `MediaFootprint.unweighed` holds one sentence per clip the record cannot locate, unless a
  walked directory holds a file of that name. It is empty when every located clip was weighed.
- `MediaVerdict.lines` prints `media unweighed  <sentence>` after the measured line, and only
  when there is something to say.

## Decisions

1. **A split at a named seam** (Ruling 261): *which clips does the record locate* is
   `recorded.py`. `footprint.py` stays *what is on disk and what it weighs*. Neither file is
   near R11's ceiling. The split is by question, not by size.
2. **The widening is in `measure_directories`, not only in `measure`.** Both are public, and
   both are called a footprint. A reading that widened under one name and not the other would
   leave a caller that holds its own directories under-counting in silence.
3. **An unreadable record refuses; it does not degrade to the declared walk.** A degraded
   reading is the silent under-count this row closes. Every current caller catches
   `MediaError` or is a test.
4. **"Cannot locate" is reported against what was walked, by filename.** A version-1 entry has
   no directory. If a walked directory holds a file of its name, it was weighed, and saying
   otherwise would be false. Nothing here derives where that file should be.
5. **An unweighed clip is stated and does not refuse.** The row asks for a statement by name.
   Making an `auto` verdict refuse on it would be a policy change nobody ruled.
