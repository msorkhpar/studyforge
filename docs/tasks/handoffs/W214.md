## What landed

### 1. The tree is computed, and the page shows it

`archive_tree()` asks `Layout` for four paths — at a real address, a real
variant, unit 1 and a real ordinal, because `Address` refuses `<address>` and
`unit_name` refuses a placeholder — and then substitutes **one path segment at a
time**. A text replace was refused: it would be free to rewrite a character
inside `archive`, `raw` or `units`, which are the three segments
`corpus.placement` owns and the drawing has to reproduce untouched.

[`SKILL.md`](../../../src/studyforge/skills/adapter/SKILL.md) step 3 carries
that output verbatim, and the fourth line is the one the row is about:

- `<corpus-root>/archive/<address>/units/unit-NN/` — a unit's **own** files.
  Every `assets` and `attachments` entry's `local` resolves against it, and so
  does the authored overlay `content.json` (§5's contract table).

⭐ The page also carries a fence that prints the tree at the ref the reader is
on, on the model the check count already uses (Ruling 163): a pointer resolves
at read time, and an agent executes a fence.

### 2. `validate` has the opinion, and it is derived

`check_declared_files` resolves each entry's `local` against
`Layout.unit_files(address, unit)` and refuses three shapes under one rule id,
`media-missing`:

- the file is **absent** from that directory — including the `W214` case, media
  written under `raw/<variant>/unit-NN/` where no build looks;
- `local` names **no file** at all — which `generate.media._filename` already
  refuses outright, so `validate` may not pass it;
- `local` is not a plain location inside the unit's directory — refused by
  `sourcepath.source_path_fault`, and the refusal **names the fault and never
  the value** (R7), because every shape refused there is a candidate home path.

⛔ **Two exemptions, and both are somebody else's rule rather than this check's
invention.** A document carrying `media_skipped` is a capture that named its
media and deliberately did not fetch it (`archive.document`, and
`tests/fixture_checks/media.py` has read it that way since `FND-04`). A
document whose `unit` is not an ordinal, or is not the one its directory names,
is left alone because `structure.check_document_identity` already refuses it —
one defect must not be reported under two rules.

## Decisions

- ⛔ **RULED: the skill's tree is `archive_tree()` byte for byte, rather than
  prose beside a constant.** The row forbids *a paragraph that restates a
  constant*, and R19's test is whether a second adapter author retypes
  anything. A sentence saying *"media go in `units/unit-NN/`"* would be a third
  spelling — [`docs/authoring/archive.md`](../../authoring/archive.md) already carries the second, correctly
  — and a third spelling is what the row exists to refuse. ⭐ So the page holds
  the **output**, and an instrument holds the equality.
- ⛔ **RULED: the drawing is computed and substituted, never typed.** The
  alternative — a string constant the instrument checks against `Layout` — would
  pass the same assertions today. ⚠️ It fails differently: the constant needs a
  human edit when the layout moves, and this does not. ⭐ The instrument is
  kept **regardless of which side is implemented how**, because it is what makes
  the equality checkable from the page rather than from the code.
- ⛔ **RULED: the new check lives in `validate/source/membership.py` and not in
  `structure.py`.** `membership` already holds the one derivation of a unit's
  own directory, and it already defers the `skills.adapter` import for the
  reason that import has to be deferred. ⭐ A copy of that derivation in
  `structure.py` would be the second authority this row is about. ⚠️ The two
  checks are one question from two ends — *is every file here accounted for* and
  *is everything accounted for here* — so the package's module table now says so.
- ⛔ **RULED: one rule id for three shapes, not three.** Absent, misplaced and
  unnamed are one question to a reader and one fix to an adapter: write the file
  where `Layout.unit_files` puts it. ⭐ The reference's row enumerates the three
  so a script filtering by rule is not surprised.
- ⛔ **RULED: `media_skipped` exempts a declared entry**, and the ground is that
  the semantics were already shipped rather than that they are convenient.
  `tests/fixture_checks/media.py` has returned early on the marker since
  `FND-04`, and inventing the opposite rule in `validate` would have given one
  corpus two answers.
- ⛔ **RULED: a misplaced file is TWO findings, and that is correct.**
  `media-missing` and `archive-stray` are two different true statements — the
  file that is there is read by nothing, and the file that was declared is not
  there — and they have different remedies for an author who moved a directory
  versus one who never wrote it. ⚠️ Distinguished from the *one defect, two
  rules* case above, which is refused: there the second finding would be derived
  from the first's own disagreement.
- ⛔ **`docs/specs/` left alone.** See `W214/1`.
