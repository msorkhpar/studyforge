## Decisions

Clause 1, the design decision:

⭐ **A convention, and no `protected` declaration.** R3's content category is a property of the file in its repository, so the manifest cannot be what decides it. A `protected` field alone would leave ISO's shape declarable by any corpus that did not remember to protect its README. Adding one as well would be a schema change and a `corpus_api` bump that no witness needs, because a corpus already protects any file by not declaring it (OPS-05 rule 5). Reversible: remove `ROOT_DOCUMENTATION` and the `BY_CONVENTION` branches.

- **The convention is repository-root documentation**: a root `README`, `LICENSE`, `LICENCE` or `COPYING`. The match is on the exact stem, in any case, with any suffix. These are the repository's front page, which every host renders, and the terms every reader is bound by. No corpus is named (R1).
- **Declared, not decided:** a nested README is content only if the policy includes it, and other root documents (a contributing guide, a changelog) are outside. The root ignore file, version-control configuration, dot-directories and generated output are unchanged.
- [Spec R3](../../specs/2026-09-08-studyforge-v1-design.md) names the convention in the same diff.

## What landed

- [`edits.py`](../../../src/studyforge/corpus/manifest/edits.py): `reads_as_content(path, content)` returns `BY_POLICY`, `BY_CONVENTION` or `""`. It is the ONE predicate. The parser refuses a declaration to a convention file by name, and the policy refusal's message is unchanged byte for byte.
- [`nondestructive.py`](../../../src/studyforge/validate/nondestructive.py): `_forbidden` imports that predicate and keeps no `classify` call. The convention refuses a DECLARED change as `forbidden-edit`. An undeclared change to a root README still reads `modified`, exactly as before.
