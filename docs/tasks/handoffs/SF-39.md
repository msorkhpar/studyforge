## Decisions

- ⛔ **`--site` is required with no default**, for `build`'s `--out` reason (`W202` Q1 is open).
- **Exit codes are `build`'s**: `1` = the corpus declares a page (the plan's footprint `.html`
  plus the root index) that the site lacks, printed as `unbuilt <page>`, and nothing is bound.
  `2` = missing directory, unreadable corpus, or a port it cannot listen on.
- **`private=` names `SF-21`'s store by resolved path.** Measured: with `--site
  <corpus>/.studyforge` the static mount's prefix check (relative to the site root) does not
  see `progress/`, and dropping the predicate serves the record.
- **`started=`** is keyword-only, so the dispatcher's `run(rest, out=out)` is unchanged.

## Surprises

- ⚠️ **A plant SURVIVED the static arms**: a connect to a socket path read from `DOCKER_HOST`
  names no `docker.sock` literal and imports nothing Docker. Only the runtime decoy arm kills it.
- ⚠️ Reading a live process's `/proc/<pid>/fd` races a handler closing a descriptor; the
  first run failed on it. Vanished descriptors are skipped; the population guard stays.
