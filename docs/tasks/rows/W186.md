# W186

⛔ **This file carries the ARGUMENT for board row `W186` and nothing else.**
⭐ **Its naming, owner and state live once, in the register in [`../BOARD.md`](../BOARD.md)** — ⛔ **not here, and not in two places.**

⛔ **ROUND 19 §5.3 NAMES `data-speech-id`, THE ATTRIBUTE WAS RULED NOT EMITTED, AND §5.3 STILL READS AS AN OUTSTANDING INSTRUCTION.**

### ⛔ THE DECISION IS ALREADY TAKEN — this row is about the instruction that survived it

⭐ **Ruled during `SF-18`: the attribute is NOT emitted, because nothing reads an id off the page, and ⛔ an attribute no code reads is markup that CANNOT GO RED.** ⚠️ **A contract nothing can falsify is `W37`'s subject exactly, and emitting it would have been a check that cannot fail wearing a markup contract's clothes.**

⛔ **THE DEFECT IS NOT THE DECISION. It is that §5.3 still says to do it**, so the next office to read that section reads a live instruction and either implements it or spends the argument again.

### ⛔ WHY IT CANNOT SIMPLY BE EDITED, which is why it is a row

⚠️ **Round 19 is a RECORD, and a record is annotated beneath and never edited** (Ruling 106). ⭐ **So the reconciliation cannot happen where the stale instruction lives** — ⛔ **and that is the whole difficulty: the fix has to land somewhere a reader of §5.3 will actually reach.**

### ⛔ WHAT SETTLES IT

1. ⛔ **THE TAKER DECIDES WHERE A SUPERSEDED INSTRUCTION IN A FROZEN RECORD IS ANSWERED**, and states it out loud — ⭐ **an annotation beneath §5.3, or a live clause in the markup contract that names §5.3 and supersedes it, or both.** ⚠️ **Ruling 106 permits the annotation; what it cannot do is make a reader look for one.**
2. ⭐ **THE RULING'S GROUND IS CARRIED FORWARD, not just its verdict:** *an attribute no code reads is markup that cannot go red.* ⛔ **A reconciliation that records only *not emitted* invites the next author to re-add it.**
3. ⚠️ **THE CLASS IS CHECKED, not the instance** — ⭐ **round 19 §5.3 is where it was SEEN; whether other superseded instructions sit in frozen records is the taker's measurement at their own ref** (Ruling 214). ⛔ **No count here** (Ruling 150's form).
4. ⛔ **ASSERTED IN BOTH DIRECTIONS** (R12) if any instrument lands: an emitted `data-speech-id` must fail, and a page that omits it must pass.

### ⚠️ WHAT IT MUST NOT BECOME

⛔ **AN EDIT OF A FROZEN RECORD.** ⭐ **Ruling 106 is not negotiable and this row does not reopen it.** ⛔ **AND NOT A RE-ARGUMENT OF THE ATTRIBUTE** — ⚠️ **that was decided with a reason; this row carries the decision to where it can be found.**
