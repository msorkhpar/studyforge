### ⛔ WHY A ONE-SENTENCE DOCSTRING DEFECT IS WORTH AN ID

⚠️ **The *Depends on* line is not decoration: it is the declared module contract this project reads to decide whether an import crosses a boundary it should not** — ⭐ **and R17's whole mechanism is that a package states its edges so a reviewer can check a diff against them without re-deriving the import graph.** ⛔ **A contract that names a package nobody imports teaches a reviewer to distrust the line, and a contract that omits a real edge lets the next import cross unremarked.**

### ⛔ WHAT SETTLES IT

1. ⛔ **THE SENTENCE IS RE-DERIVED FROM THE TREE AND NOT PATCHED BY THE TWO KNOWN DELTAS.** ⭐ **`NS-05/7` measured two errors; the row asserts the WHOLE set, because a contract corrected only where somebody happened to look is the same defect one wave later.**
2. ⚠️ **THE DERIVATION IS THE INTERESTING HALF AND IT IS NOT DECIDED HERE.** ⛔ **Whether this becomes an instrument — a check that reads a package's declared *Depends on* against its actual `from studyforge…` imports — or stays a hand-corrected sentence is the taker's design decision, and it is exactly the shape `W37` and `W53` are about.**
3. ⛔ **IF IT BECOMES AN INSTRUMENT IT IS ASSERTED IN BOTH DIRECTIONS** (R12): a package naming an unimported dependency FAILS, a package omitting a real one FAILS, and a correct package PASSES — ⭐ **and the passing arm needs a real package, not a fixture with one import, or it is born vacuous** (Ruling 48).
4. ⚠️ **THE POPULATION IS NOT ONLY `narrate`.** ⛔ **Two measured errors in one package is one reading; whether the rest of `src/studyforge/` is clean is UNMEASURED, and the row states that rather than assuming either answer.**

### ⚠️ WHAT IT MUST NOT BECOME

⛔ **A REWRITE OF THE DOCSTRING'S PROSE.** ⭐ **The *Depends on* sentence is the subject; the module's argument above it is not, and a row that arrives to fix a contract and leaves having re-styled a docstring has spent a slot on taste.** ⛔ **AND NOT AN IMPORT CHANGE** — ⚠️ **`describe` is a legitimate dependency that `NS-05` added deliberately; the defect is that the contract does not say so.**
