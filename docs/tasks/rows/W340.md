⚠️ **R1 is NOT violated by this and the row must not be read as if it were:** ⛔ **the mapping arriving as MANIFEST DATA is precisely R1 satisfied** — the framework learns a source-specific fact as data instead of as code.

### ⛔ WHAT SETTLES IT

1. ⛔ **A corpus declares where its curriculum lives and how its filenames map to containers, IN THE MANIFEST**, and the adapter reads it from there rather than carrying it.
2. ⛔ **The reconnaissance skill WRITES what it detected into that declaration** (`F6`) — ⭐ **so detection and declaration are one act, not two.**
3. ⚠️ **A corpus that declares neither still works** — ⛔ **this may not become a requirement that breaks a corpus with a simpler shape.**
4. ⛔ **Asserted both ways (R12):** a second corpus with a different prefix shape is filed correctly from its manifest alone, and a manifest whose declaration disagrees with the tree REFUSES.

⭐ **Surface:** the manifest schema, the reconnaissance and adapter skills, and their tests. ⚠️ **It touches `SF-02`'s contract, which R9 makes expensive to alter after it ships — so the shape is argued before it is written.**
