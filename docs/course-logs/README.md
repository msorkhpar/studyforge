# Course logs

Each course built with StudyForge writes a findings log at
`.studyforge/findings.md` (the onboarding skill, step 7) and sorts it (the
delivery skill, step 9). The sorted log is filed here, named after the
corpus's `source`, so the reasons behind every catalogue entry and framework
task stay with the framework.

A new course reads the catalogue first (`python3 -m studyforge.skills.catalogue`),
not these logs. The logs are the evidence; the catalogue is what was kept.
